# 第1至58章一致性修订设计

## 目标

只修复作者确认的四类硬问题，并清除发布稿中的章末自检行；不处理问题清单中的其他留白，不扩写情节，不改变人物走向。

## 修订范围

1. 第二份幽禁令的认知误判：
   - 第49章将吴内侍的浮字改为转述何崇说法，明确吴内侍没有亲自确认匣底。
   - 第56章将吴内侍的失言和苏合的判断统一改为“始终以为批文在乌木匣”，保留高潮中的反转力度。
2. 青花碗、旧印和请释副签回流：
   - 第17章补入一段最小说明：苏蕙离宫前把副签正文另藏进旧库木匣；病重前托人将装有旧印和两角残签的青花碗送回柳婕妤。
3. 日期错误：
   - 第14章“昨日”改为“三日前”。
   - 第24章“第七日”改为“第十八日”。
4. 能力载体表述：
   - 第46章将“数清使用青花碗次数”改为“数清借菜看字次数”，不再暗示青花碗是唯一触发载体。
5. 发布稿清理：
   - 核对第1—5章是否存在自检行。
   - 在第1—58章六份合订稿中，只删除以 `【本章事件】` 开头的整行。
   - 保留所有浮字、心理显字和其他使用 `【】` 的正文内容；保留章节分隔线。

## 明确不改

- 护送单、旧借条、苏蕙腰牌等首次出现的留白。
- 辛十三毒物的封存与下落。
- 其他未获作者确认的问题清单条目。
- 第1—58章的情节结构、人物关系、章节标题与浮字内容，除第49章指定浮字外均不改。

## 验收方法

1. 全书检索 `^【本章事件】`，结果必须为0。
2. 修改前后统计独立浮字行；除第49章指定句发生文字变化外，数量不得减少。
3. 随机抽查第1、13、29、46、56章，确认浮字仍在，章末自检行已删除。
4. 复查五个指定修订点的上下文。
5. 查看版本差异，确认没有触碰清单中其余问题或非目标正文。
