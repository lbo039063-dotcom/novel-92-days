# 《九十二天后我会死，幸好我的菜会说话》首章八版写作设计

## 目标

为同一故事制作八个切入点完全不同的第一章版本，用于筛选最有吸引力的免费网文开篇。八版共享同一设定与核心事实，但场景调度、信息出现顺序、冲突动作和笑点设计不得机械复用。

## 依据与优先级

1. 用户本次要求：按照主文稿和写作规范产出。
2. 《古言写作规则 v1》：结构与节奏规则，优先级最高。
3. 《九十二天后我会死，幸好我的菜会说话》设定包：人物、金手指、倒计时与八种切口。
4. 三本参考作品：只提炼开篇钩子、信息释放、反差塑造、围观反馈和章末悬念，不复制情节或措辞。

## 交付物

- 一个 Markdown 成稿，包含 V1—V8 八个完整版本。
- 每版标题固定为“第一章　穿书第一天，我的菜说话了”。
- 版本之间用 `=====` 分隔。
- 每版末尾附一行自检，标明钩子、两处笑点和倒计时落地段落。

## 每版共同硬约束

- 以 1800—2000 字为目标，不超过 2000 字。
- 在第一章内同时落地：苏合的身份与绝境、“食心”金手指、原著第 92 天暴毙的明确倒计时。
- 只推进“苏合穿书并确认自己必须自救”这一件核心事件。
- 至少一次正面冲突，并在本章当场得到结果。
- 至少两处由人物处境和认知反差自然产生的笑点。
- 章尾必须给出新信息，令读者产生“她为什么会在第 92 天死”的疑问。
- 有名字的出场人物不超过三人，限定为苏合、小满、冯全。
- 单段不超过五行，不写长段设定说明。
- 金手指只在苏合亲手做、对方咽下的食物上生效；只显示当刻最响的一句话。
- 不提前解释裴宴的异常，不让裴宴正式出场。

## 八版切入与差异化策略

1. V1：从苏合的手即将伸进滚水切入。主打动作危险与身体本能。
2. V2：从冯全的辱骂切入。主打压迫、嘴仗和即时反制。
3. V3：从菜面突然浮字切入。先展示奇观，再倒叙补足穿书身份。
4. V4：从原主藏起的具体物件切入。以物件串联下毒旧案和死亡信息。
5. V5：从旁人议论“下毒案里最后活下来的宫女”切入。先建立外部目光与危险身份。
6. V6：从苏合计算日期切入。把 92 天倒计时前置，随后验证金手指。
7. V7：从冷宫深处门后的动静切入。只作为远景异响与悬念，不让男主正式登场。
8. V8：自由切口，采用“食物被打翻后字仍浮在汤痕里”的视觉事件，强化记忆点。

## 参考作品的具体借鉴

- 《恶毒贵妃又又作死》：学习弹幕式碎片信息、女主吐槽反应和即时反差笑点；避免依赖露骨桥段与过量网络梗。
- 《手握太子亡魂，旧梦逢生》：学习单一异象逐步显形、具体物件承载秘密、章尾用身份关联制造新信息。
- 《枝上蘅》：学习绝境中立即行动、能力展示的围观反馈、第五章男主登场的铺陈方法；首章不照搬系统任务或身份揭晓模式。

## 质量验收

- 八版首句和前 300 字的信息顺序明显不同。
- 八版的冲突解决动作、两处笑点和章尾措辞不重复套模版。
- 不出现设定冲突、人物越界、金手指无代价使用或全知读心。
- 每版读完都能准确回答：她是谁、她能做什么、她何时会死。
- 重点候选为 V1、V3、V6，分别测试强动作、金手指奇观和倒计时前置三种开篇模型。
