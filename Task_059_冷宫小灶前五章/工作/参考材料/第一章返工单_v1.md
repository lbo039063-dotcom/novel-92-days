## 一、八版评审结论

### 通过的部分

- 冲突当场出结果,围观者有反应
- 章尾均为新信息钩子,无一例外
- 笑点密度达标,其中若干句质量很高:
  - 「公公,您的令牌缩水了」(V1)
  - 「多劈一根,能少刷一只吗」(V2)
  - 「饿的时候,是肉味」(V2)
  - 「四脚朝天的王八」(V6)
  - 「泔水还没追您」(V7)

### 三个必须修的问题

**问题 1｜八版中段完全同质**

八个版本的中段全部是同一套:冯全进门 → 威胁扣饭 → 苏合顶嘴 → 围观憋笑 → 冯全退走。
差异只存在于开头和结尾。这不是八个版本,是一个版本的八个开头。

**问题 2｜金手指规则被写成了说明书(最严重)**

八版全部出现类似段落:

> 「她逐渐弄懂:必须亲手做、对方咽下;只显当下最响的一句;同一人一日一次;越用心字越清晰。」

这是设定文档的内容被原样搬进了正文。

**参照对象的做法:样本一(弹幕流)从第一章到第五章,从未用一句话解释过弹幕的规则。** 读者是自己看明白的。

规则必须靠**行为差异**呈现,不靠总结陈词:

- 她敷衍煮的东西浮出糊字 → 读者自己发现「用心才清楚」
- 小满吃第二口没有字 → 读者自己发现「一天一次」

**正文中禁止出现任何一句对金手指规则的归纳性表述。** 一句都不行。

**问题 3｜倒计时落地过晚**

各版自检行显示倒计时分别落在第 74–83 段,即全章最后。
只有 V6 落在第 1 段。这是选 V6 为底的首要原因。

## 二、定稿结构(严格按此顺序写)

### 第一章　穿书第一天,我的菜说话了

**① 开篇(保留 V6 原样)**

苏合用木炭在灶墙上写下「九十一」。写完又数一遍。
倒计时在第一段落地,不得后移。

**② 身份与穿书交代(保留 V6,压缩三成)**

现代餐馆帮厨 → 《凤台记》同名炮灰 → 原著只给了「粗使宫女苏合暴毙」七个字。

**③ 她盘算出路(保留 V6)**

逃出宫 / 装病 / 抱女主大腿,三条路逐一否掉。
这段是全章最能立人设的地方,一个字不要删。

**④ 小满登场 + 湿柴 + 王八笑点(保留 V6)**

**⑤ 新增:铜簪(从 V1 移植)**

小满是哭着进来的。东偏殿丢了一支铜簪,冯全一口咬定是她偷的,扬言明早搜铺,搜不到也要打十板子。
小满不敢辩白——她怕的不是挨打,是被赶出冷宫。

**这条线在本章不解决,留到第二章。**

**⑥ 冯全冲突:食盒 + 簸箕 + 金鸡独立(保留 V6 原样)**

这是八版里唯一有肢体喜剧的冲突场,爽点四拍齐全,原样保留。

**⑦ 煮粥**

保留 V6 的湿柴烟熏细节和熬粥过程。

**⑧ 金手指首秀(关键改动)**

小满喝下第一口,粥面浮出的字改为:

```
【铜簪不是我偷的。】
```

**不要用 V6 原来那句「她说自己九十一天后会死」。**

理由:第一次动用金手指时,浮出的字必须落在**另一个角色自己的委屈**上,而不是落在女主的处境上。读者第一次见到这个能力,同时共情了小满。V1 在这一点上是八版里做得最对的。

**⑨ 规则试探(重写)**

保留行为,删除总结:

- 让小满再吃一口 → 没有字
- 给她吃别人留下的冷窝头 → 没有字
- 随手敷衍煮一勺糊 → 浮出的字糊成一团

三个动作写完就走,**不许接一段「她逐渐弄懂……」**。
可以留一句短的玩笑收尾,但不许归纳规则。

**⑩ 结尾:那扇门(从 V7 移植,并改写)**

夜里,冷宫最深处传来铁器撞石门的声音。
一声,一声,间隔分毫不差。

苏合走到窗边数。

**数到第九十二声,整座冷宫彻底安静。**

她看向那道从外面锁死的黑门。石阶上不知何时又多了一只空碗。

碗底用炭写着两个字:

```
苏合。
```

**这里必须用她自己数,不能用浮字。** 金手指规定一人一日一次,小满的额度已经用在铜簪上了。让苏合亲耳数出九十二,比浮字更冷,也更省。
