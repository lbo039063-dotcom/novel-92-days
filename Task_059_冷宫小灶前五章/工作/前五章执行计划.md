# 《九十二天后我会死，幸好我的菜会说话》前五章 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 保留 V1 为第一章，完成第二至第五章并交付符合两份指导文档的前五章合订稿。

**Architecture:** 每章单独起草、统计和验收，后章只继承前章已经落地的事实。全部单章通过后再合并，最后执行跨章人物、时间、金手指、悬念与重复表达检查。

**Tech Stack:** 中文 Markdown、PowerShell 只读统计、逐章人工叙事验收。

## Global Constraints

- 每章 1800—4500 字。
- 每章只推进一件核心事件，至少一次正面冲突并当场出结果。
- 每章至少两处笑点，章尾必须是新信息。
- 前五章命名人物限定为苏合、小满、冯全、柳婕妤、裴宴、周内官。
- 第五章男主外貌描写不少于 300 字，并写小满、柳婕妤、冯全的反应。
- 金手指四条限制不得放松。
- 第一章 V1 原样保留。
