# 卷七《北地》第105—128章写作任务

## 一、承接事实

- 苏合已依制度升为一等女厨，掌尚食末灶与冷宫小灶；她的私册曾被拆页描录，幕后者已在追查食心使用轨迹。
- 苏合与阿绫的味觉都没有恢复。卷六末苏合连质地也分不清；本卷进一步只剩烫、温、凉三级感受。
- 何崇已在勘问后院死亡，确切死因未明。他留下二十年前北路第七驿食单：苏蕙离宫第七日抵驿，同行三人，自带米、借灶煮粥，辛料另封。
- 裴氏母族二十七人十三年前被逐北地。卷七找到其中六名活人，母族名册是裴宴合法出京的明面理由。
- 二十年前停料令签名只露过一个未向读者展示的字；不能让档案直接给出答案。

## 二、全卷硬约束

- 共24章，每章以2000—2400个非空白字符为目标；每章只推一件核心事件，有当场落地的冲突结果和新信息钩子。
- 场景离宫，在驿站、军屯、边镇集市、雪路、野灶、烽堡、废驿之间轮换。证据来自灶痕、活人口述、衣色、封蜡、马路与饭食记忆，不把北地写成换皮档房。
- 所有做饭都受坏料、坏灶与严寒限制：冻水、湿柴、裂锅、冻面、冷肉、风口、汤离火即凉。
- 苏合入口只能辨烫、温、凉。她用白气、汤痕、勺柄阻力、筷压、时辰和他人复味掌灶；只演动作，不总结病情。
- 阿绫味觉不恢复。柳婕妤、韦典膳留宫。苏蕙两名同行者不在本卷强行揭晓。何崇死因仍不定论。
- 第124章不查案、不追人、不使用浮字，只写苏合为六人做饭。
- 曹德安不洗白。他的最后一趟差完成闭环，却不能抹去他曾替何崇和顾延章办事、参与把裴宴送进冷宫的事实。
- 幕后者不在北地正面出现；本卷只确认姓名与当下身份，不解释其终极目的。

## 三、本卷新增设定

### 3.1 六名幸存者

| 人物 | 十三年前身份 | 现状 | 记住的饭食细节 |
|---|---|---|---|
| 罗六娘 | 裴府外灶帮厨 | 边镇卖干菜 | 冻蔓菁不削皮，切大块才够分 |
| 秦岳 | 车夫兼护院 | 白河军屯养马，左腿跛 | 从旧锅沿刮半勺羊油润锅 |
| 祝阿婆 | 针线房管事 | 集市缝毡靴 | 粟米先干焙，开锅有细响 |
| 范小刀 | 八岁旁支幼童 | 边镇屠户学徒 | 冻面不用擀，敲松后手揪下锅 |
| 杜青禾 | 药房使女 | 军屯采药换盐 | 盐离火后才放，逐碗问人再补 |
| 卫长庚 | 十六岁书童 | 烽堡轮值伙夫 | 最小的孩子碗底藏半块烤饼 |

六份记忆拼成一锅焙粟羊油蔓菁面片汤：焙粟、刮羊油、带皮蔓菁、手揪面片、离火下盐。十三年前只给年纪最小的几个孩子藏饼；第124章复刻时把三块烤饼分成六半，六人每碗各压半块，因为今日六个人都曾是那锅饭里被照顾的人。

### 3.2 苏蕙北地时间线

- 二十年前：离宫第七日抵北路第七驿，同行三人，辛料另封。
- 离宫后第一至第二年：沿北路替驿站做饭换宿，后停白河军屯掌冬灶。
- 第三年：到边镇南集，以野灶与面摊为生，暗查将被牵连的裴氏旧人。
- 第四至第五年：在烽路沿线替换防冬粮，教人用湿柴、裂锅和冻料出饭。
- 第113章的六年轨迹取证：十三年前折返夜，苏蕙在饭桌上亲口讲给祝阿婆；祝阿婆后来以六处不同灶泥及鞋底旧补料逐一认明，属于听后辨认，并非前六年的亲历。
- 第六年：回雁回驿，把灰蜡辛料罐封进废灶夹墙，交给不识字的老驿卒赵五。交罐路线、布包针脚与入灶封芦苇均仅赵五亲见；此时六名幸存者尚未迁逐北地，也没有预设其去处或记号。
- 十三年前：苏蕙离开北地约一年后，裴氏二十七人被逐。她当年冬天短暂折返，为众人做饭，并与六名幸存者逐一发生联系；饭前把一块灰蜡交给祝阿婆作认人凭记，饭后再去雁回驿，把六人的去处、记号及“重新叫齐方可交罐”的规矩交代赵五，次日再度消失。六名幸存者记住的是这一顿。

### 3.3 幕后者

- 新增姓名：顾延章。
- 性别与身份：顾延章，女。二十年前为尚宫局掌籍女史，负责内廷名册、文匣及内外传书；现任尚宫，掌内廷文籍、女官调度、宫宴总检。
- 老驿卒赵五不识字。他记得雪夜送信者穿紫酱色罩衣，袖缘压一道鸦青线，衣襟内层与苏蕙封罐布同色；更记得驿丞当面称其“顾延章”。
- 第80章残签露出的字定为“章”。第127章只能用它做口述之后的第二重印证。
- 姓名确认的真源是赵五的亲口证言，不是档案反查。

## 五、逐章章纲

105《这趟出京，我只带会做饭的人》：裴宴获准以续修母族名册出京。有人拿苏合失味阻拦，她用随行复味安排和路膳实做当场过关。曹德安主动同行。章尾：二十七个旧名旁，只有六处没有死记。

106《出了宫，殿下也要等人开门》：城门、驿门与风雪同时拦路。苏合用冻饼和半锅水做第一顿路饭，只看白气判断温度。小内侍浮字。章尾：废弃的北路第七驿墙上仍有“借灶半日”的刻痕。

107《她二十年前借的，就是这口灶》：苏合阻止当地人拆旧灶，用灶底米壳、烟路与食单位置证明苏蕙借过此灶。章尾：灶壁内有一根只在更北军屯使用的白桦火签。

108《湿柴烧不着，今晚也得有热饭》：暴雪困驿，野灶反复熄火。苏合带人垒雪墙挡风，以余炭和油布引火做成热饭。章尾：换马屯卒认出火签，十三年前的跛脚车夫秦岳还活着。

109《二十七个人里，第一个还活着》：先在边镇集市找到罗六娘。她拒认旧身份，苏合从其切冻蔓菁的动作和迁逐细节确认。章尾：当年有人来接他们，却死在前一站。

110《来接我们的人，先死在了雪里》：苏合亲手做蔓菁汤，罗六娘浮字。她承认苏蕙十三年前折返过北地，并指向秦岳。章尾：秦岳逢京城来人便躲。

111《军屯没有白米，只有冻住的粟》：苏合先解决军屯裂锅、冻粮和定柴晚饭，再见秦岳。秦岳从粟粒爆响认出苏蕙焙粮法。章尾：他肯见裴宴，却不肯跪。

112《你母亲那边的人，不欠你下跪》：裴宴不索跪礼，只问秦岳是否愿意把名字写回名册。秦岳暂不回京，却交出其余旧人去处。章尾：有人替苏蕙保管过十四年的东西。

113《她在北地做的六年，不是为了查案》：沿饭食与旧灶痕找到祝阿婆；苏蕙十三年前亲口讲述前六年轨迹，祝阿婆再以灶泥、鞋底旧补料旁证。章尾：第六年离开后，她十三年前又回来过一夜。

114《那顿饭以后，我再没见过苏娘子》：苏合做焙粟汤，祝阿婆浮字。祝阿婆给出边镇南集方向及苏蕙十三年前饭前留下的灰蜡认人凭记。章尾：灰蜡纹路与冷宫料罐一致。

115《这碗面没擀过，是冻硬后揪下来的》：南集缺水、面硬，苏合照记忆用刀背敲面、手揪下锅。罗六娘拆穿冒认身份的范小刀，随后以童年伤痕确认。章尾：范小刀记得十三年前苏蕙饭后单独找过杜青禾，并往雁回驿方向离开。

116《活着的人，不肯再进一次名册》：四名旧人第一次碰面，对回京意见相反。裴宴允许在册上写“不归京”，不以忠孝逼人。章尾：杜青禾正准备离开白河屯。

117《她不肯留下，我先替她把药锅烧开》：追上杜青禾。苏合先把药锅与饭锅分开，做成屯中病人的药饭。杜青禾确认十三年前苏蕙只带裂锅、没有陌生罐子入饭，并说明饭后苏蕙独自去了雁回驿。章尾：苏蕙十三年前那夜去的是雁回驿。

118《六个人，都还活着》：杜青禾浮字，补出十三年前苏蕙问赵五是否还在；杜青禾明确自己十四年前仍在京城、从未抱罐。她带众人找到烽堡伙夫卫长庚，六人全部确认。章尾：十四年前赵五已守罐，十三年前苏蕙才联系六人并把去处与记号带回雁回驿。

119《老人不识字，却记得送信人的衣裳》：老驿卒赵五因惧怕拒说。苏合做饭触发浮字后不逼姓名，只问服色。赵五亲口描述紫酱罩衣、鸦青袖缘和内衬。章尾：裴宴认出这身衣裳属于谁，但没有说名。

120《曹德安说，这一趟我自己去》：冬封驿仓藏有旧屯名册，必须赶在大雪前取回。曹德安因熟悉旧口令与旧债，坚持承担最后一段路。苏合陪到分路驿。章尾：他请她次日动身前做一顿普通路饭。

121《这回，我把他们的名字送回去》：苏合亲手为曹德安做最后一顿饭，他咽下后出现此生本卷唯一浮字。曹德安带两名驿骑去取名册。章尾：三日后先回来的只有空马。

122《名册回来了，曹德安没有》：众人沿雪路找到曹德安。他死于暴雪、旧伤与坠坡，是否有人为因素不定；名册贴身油布封好。裴宴拒绝让他无名而死。章尾：最后一页有他补上的六个旧称。

123《六个人记得的，原来是同一顿饭》：苏合逐个问那顿饭的具体动作与碗中物。随行军屯伙夫浮字。六份不同记忆最终拼成一锅完整饭。章尾：六个人第一次同意坐到一桌。

124《我做不出她的味道，只能做你们记得的》：纯情绪章。苏合靠六人复味，在裂锅野灶上做成焙粟羊油蔓菁面片汤；三块烤饼分成六半，六人每碗各压半块。无人说像，六人却因各自记忆都在碗中而哭。章尾：六个人、六只空碗，第一次共同承认“自己的那一口都在”。

125《那只灰蜡罐，在废灶里等了十四年》：饭后赵五交出钥匙与“西灶第三块护火砖后”的藏点，众人打开废灶夹墙，取得辛料罐。十四年前交罐路线、布包针脚与入灶过程仅赵五见证；十三年前苏蕙折返后才补交六名活人的去处、记号与交罐规矩，且未取罐。无人试吃。章尾：封布内层与送信者衣襟同色。

126《这种颜色，我只在一个人身上见过》：裴宴以亲眼记忆确认服色指向一名疑人，并先把未确认疑名写在单独纸上交苏合封存。裴宴浮字。苏合核对残签“章”字吻合，但不念出，姓名栏仍空。章尾：曹德安遗物中有一段同色旧衣绦。

127《这个名字写得下，却没人敢念》：众人在收拾曹德安遗物、准备返程时完成证据互证；赵五最终复述驿丞当年的称呼“顾延章”。结论达到可确认，仍不足以公开指控。章尾：苏合把写有姓名的纸放在曹德安带回的名册旁。

128《我把那个名字说出来以后，屋里没有人出声》：六人续入母族名册并决定同行回京；曹德安葬在北地，碑上写明姓名与最后差事，不抹其旧过。临行前苏合第一次说出“顾延章”，满屋沉默。最后新信息：六人中有人记得，十三年前那顿饭后苏蕙也问过这个名字。

## 六、审查清单

- 六名幸存者是否恰好六人，出现次序、年龄与十三年前身份无冲突。
- 苏蕙“二十年前离宫—北地六年—十四年前仅赵五见证交罐—十三年前折返联系六人并补交记号”的时间线是否始终一致。
- 曹德安最后一顿是否确由苏合亲手完成并当场食用；死亡是否落在回程路上；名册是否完整带回。
- 第124章是否完全不查案、不浮字、不写“味道一模一样”。
- 浮字是否恰好8处且没有让旁人看见。
- 苏合是否始终只能辨烫、温、凉；阿绫是否始终尝不出味。
- 顾延章的名字是否由赵五口述确认，衣色与残签仅作互证；不能写成档案查名。
- 第128章是否完成六人回京、名册续记、曹德安北地安葬及满屋沉默四项收束。
