# 卷六《记档》第81—104章事实摘要

## 一、逐章事实

| 章 | 主要进展 | 章尾新信息 |
|---|---|---|
| 81 | 新任韦典膳推行统一灶册，要求末灶原册统一归档。她真心相信集中保管能防篡改。 | 统一册样新增了“复味后至装盒前”一栏，正对第68章曾被利用的空档。 |
| 82 | 苏合不能反对自己立下的记册规矩，争取逐页验污、验折、验签后封存原册。 | 原册当日才入档，封套编号却早一日写入内廷收档簿。 |
| 83 | 全局首次按统一格式开灶，签押拥堵导致误火；苏合重排报数、看火、执册位置救下饭食。 | 三口误火的锅尚未出锅，册上已有完整出锅时辰。 |
| 84 | 送膳老宫人认出归档册页折角不对；众人用折痕、油点和线孔证明页被换过。 | 假页上的签押全是真的，但分别取自不同日子。 |
| 85 | 苏合已分不清粥的稠稀，改用挂勺、汤痕、落勺声判断；同数复做却得到不同成品。 | 两口同号锅的锅口与锅底厚薄不同。 |
| 86 | 一锅坏饭有三名复核者的真签。苏合证明问题落在秤砣误差、换锅尺寸和装盒余热之间。 | 新锅不是随手发放，而是有人持无名窄条指定送入前灶。 |
| 87 | 韦要求料房旧账统一入档，管库女厨担心缺失联单永远找不回来；旧账先誊后交并核页数。 | 目标料领出记录比停料回执少一联。 |
| 88 | 通过旧方、器具、药气与分层摆放复验，确认目标料不是调味，而是以辛气遮盖苦药气。 | 三个月前御膳案那道菜，本来就与黄连、苦参等极苦药物同送。 |
| 89 | 重查三个月前旧案，确认毒在药盏，辛料在菜上，两者并非同锅；辛料用途是让人不察觉持续服药。 | 二十年前驿路食单也使用“先药后膳”的摆法。 |
| 90 | 钱三娘凭旧提盒与驿记确认辛料曾用于压苦药气，北地三处驿站沿路少量续领。 | 这些领料记录像同一支车队一路使用、一路补给。 |
| 91 | 急膳因补签规则被卡，苏合与韦确立“先救饭、后补记但不得补签”的临时页。 | 正式规则出台前，已有同式临时页被用来调走旧册。 |
| 92 | 阿绫第一次独立掌一顿饭，她与苏合都不靠自己的舌头，借众人复味把饭做成。 | 柳婕妤右手端半碗汤走了三步，一滴未洒。 |
| 93 | 苏合按手续申请探视何崇，最终获准三日后见面。 | 探视簿上，苏合之前已有一条无名访客记录。 |
| 94 | 陆清衡以纸纹、折痕和印泥证明统一样册在正式下发前已被使用，且纸来自勘问后院。 | 样册泄露早于韦典膳到任。 |
| 95 | 苏合首次见勘问中的何崇，只问签令者姓名；何崇承认有人能看勘问记录，仍拒绝给名。 | 他约苏合三日后再来，并点名要一碗最普通的面。 |
| 96 | 苏合亲手做汤面。何崇交出二十年前北地驿站食单，纸上有苏蕙字迹；他仍不说名字。 | 何崇第一次也是唯一一次浮字，决定“不再怕”；他让苏合三日后再来。 |
| 97 | 苏合按约赴后院，得知何崇昨夜病故；饭食、值守、遗物都被完整手续挡回。 | 病故记录底册的收档时辰早于报死时辰。 |
| 98 | 经核验，提前收档可由“先收空栏底册、后补记”解释，所有手续成立，没有足够证据重验。 | 唯一未被收走的是北地食单，因为档中从未登记过它。 |
| 99 | 苏合从食单的菜量、驿印、借灶与自带米确认苏蕙确实到过北路第七驿。 | 食单日期在苏蕙自请离宫之后七日，同行共三人。 |
| 100 | 换页事件令统一灶册面临废止；苏合与韦形成原册、誊本分置及页码、骑缝、短凭互证方案。 | 第一批双份册中，只有苏合的原册与誊本页数不一致。 |
| 101 | 多出黄页抄自苏合私册。韦亲自走完收令、用印、调册链，确认自己被人利用，撤回单方收册令。 | 被定向调看的不是旧案证据，而是苏合借饭查事的日期、对象和次数。 |
| 102 | 统一格式和归档保留，新增双份分置、三处骑缝、个人短凭与调册留痕，灶册成为公开明规。 | 一张无款“上意”要求例外封收旧案册，因无人肯署名而未执行。 |
| 103 | 尚食局依据掌灶、救灶、出膳与制度记录，按旧例核定苏合升为一等女厨，不是私人提拔。 | 交接清点发现苏合私册中间一页纸纹异常变薄。 |
| 104 | 苏合确认该页曾被拆下覆纸描录再放回，抄走的是历次食心使用轨迹；原页及副本分开封存。 | 那只手关注的不是案子，而是苏合本人及她的能力。 |

## 四、关键物证与未结事项

- 目标辛料用途已确认：以辛烈气味压住苦药气，便于让服药者不知情地把药咽下；其毒性和苏合、阿绫失味机制仍未确定。
- 三个月前御膳案由“单纯下毒”改判为“毒与长期掩药手法并存”，但药物目的、命令来源仍未查清。
- 北地食单日期为苏蕙自请离宫后第七日；地点为北路第七驿；人数三人；苏蕙自带米、借灶煮粥，并写“辛料不入汤，另封”。同行者和后续去向未明。
- 何崇已死，真实死因没有证据定论；二十年前签发原停料令的名字仍未获得。
- 幕后者可接触“上意”、空白解释短条、勘问后院纸张与尚食局调册链，但正文未确定其姓名、官职、相貌或具体身份。
- 苏合私册被拆页描录；被抄内容是食心使用的日期、对象和次数，不是浮字原文。幕后者对食心掌握到何种程度仍未明。
- 灶册制度最终保留：原册统一归档，浅黄誊本留灶，两份分置；每页编号、三处骑缝；签押者各持短凭；调册须记时辰、去处、经手人；急膳可先救饭后补记，但不得补签。
