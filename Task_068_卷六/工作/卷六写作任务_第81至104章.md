# 卷六《记档》第81—104章写作任务

## 一、承接状态

- 第80章后，何崇被收走掌印，留在外廷勘问后院；他承认原停料令不是自己签的，但拒绝说出签令者。
- 苏合同时掌“尚食末灶”和“冷宫小灶”，依靠分量、刻数、火位、多人试味与签押做饭；她尝不出味，但嗅觉无异常。
- 阿绫完全失味；柳婕妤右手能端轻物，尚不能稳端满碗；裴宴住西偏殿；曹德安协助外廷核旧卷。
- 苏合手里有苏蕙字条；原停料令残缺签名仍不可辨，不得公开第80章看见的单字。
- 二十年前目标料被以“气味辛烈，易掩药味”为由停用；十三年前冷宫灶下封存单、裴宴幽禁令、母族迁逐令同日。

## 二、本卷核心冲突

新任尚食局典膳女官韦典膳奉“上意”推行并接管灶册。她不贪、不恶、只执行，主张与苏合当初立册的理由一致：既然三人复核有效，就应统一格式、统一签押、统一保管。

苏合若反对，就是反对自己立下的规矩；若同意，就失去自己手里唯一的证据链。冲突不能靠证明韦典膳是坏人解决，而要让“正确的制度如何被另一只手利用”在具体饭食、交册、调册、补签、归档中发生。

## 三、全卷硬约束

- 共24章，第81—104章；每章2000—2600个非空白字符，单章只推一件核心事件。
- 每章至少一场当面冲突并在本章产生阶段结果；笑点尽量来自小满、钱三娘、曹德安等人的性格与饭食，不机械安排围观起哄。
- 章尾必须给新事实或改变读者理解的信息，不写空泛预告。
- 不揭示幕后“那只手”的姓名、官职、相貌；不让其正面登场。
- 味觉不恢复，不归纳机制。卷中苏合进一步尝不出质地：只用挂勺厚薄、筷子插入阻力、锅边汤痕、落勺声音等动作呈现。
- 阿绫味觉不恢复；柳婕妤右手循序恢复；裴宴不替苏合做关键决定。
- 浮字严格8处，须满足“苏合亲手做—对方咽下—字浮在剩余食物表面”。不得增加或调换。

## 五、章节设计

### 第一段：制度进场（81—88）

81《从今日起，册子不归掌灶的人》：韦典膳到任，宣布全局统一灶册并收回原册。她吃苏合亲手做的清粥，浮字证明其真心认为统一保管可防涂改。苏合交出末灶新册的誊本，暂留原册。章尾：韦拿出的统一册样，最后一栏正是第68章被人利用过的“复味后至装盒前”。

82《你立的规矩，为什么你先不肯交》：韦要求原册入档，苏合无法用“怕被改”否定所有人共同签押的制度，只能要求交接时逐页验线、验污、验签。阶段结果：原册当众封存。章尾：封套编号早一日已写进内廷收档簿。

83《一百二十口锅，都要写在一张纸上》：全局第一次按统一格式开灶，灶上因人人等签押而误火。苏合用具体分工救下一批饭，但不否定记册。章尾：误火的三口锅，记录上却早已有完整出锅时辰。

84《这页不是我们送进去的》：送膳老宫人对一页签押提出异议；吃苏合所做饭后浮字指出页角不是她折的。众人用折痕、油点和装订线证明归档后换页。章尾：假页所有签名都是真的，只是来自不同日子。

85《粥稠不稠，勺子先知道》：苏合第一次明确表现无法辨粥的稠稀。她不说失去质地，改看挂勺、汤痕和落勺声完成一锅粥。韦认为这更证明统一记录必要。章尾：同一套数据在另一口锅复做，成品却完全不同。

86《三个人都签了，坏饭是谁做的》：一锅有问题的饭拥有三人真签，责任在记录链里被摊薄。苏合追到秤砣、锅口与记录格式没有标明的差异，证明“数对、锅不对”。章尾：统一册只记锅号，不记锅口尺寸，而新换的锅是有人指定的。

87《旧账匣也要统一入档》：韦要求料房旧账一并收档。管库女厨吃苏合做的饭后浮字，暴露她怕的是二十年前旧账从此离开眼前。苏合提出先誊后交并让所有旧账持有人签页数。章尾：目标料的领出旧页比停料回执少了一联。

88《这味料不是为了让饭更香》：通过旧方、药渣和当年器具复验，排除调味用途，查明其辛烈气味能盖住苦药味；不入口试毒。章尾：三个月前御膳下毒案那道“用料不对”的菜，原本就配了一味极苦的药。

### 第二段：旧案回扣与情绪章（89—96）

89《三个月前那碗，不是为了毒死他》：回查卷二御膳案，发现毒与掩味料并非同批下锅，目标可能是让中毒者在不知情下持续服某种药。阶段结果：确认苏蕙追查的正是这套掩药法。章尾：二十年前驿路食单上也出现过相同的“先药后膳”记法。

90《苦药下去，汤还是香的》：钱三娘凭旧闻与不入口的蒸气、药罐痕迹协助验证用途；她吃苏合所做食物后浮字确认当年有人用它盖苦药气。章尾：旧料不是宫中独有，二十年前北地驿站曾领过。

91《册子记得住，人却等不起》：统一灶册全面推行，一场急膳因补签被卡。苏合与韦正面冲突，最后启用“先救饭、后补记但不得补签”的临时页。章尾：有人在正式规则出台前，已用同样临时页从档中调走一册。

92《阿绫，这顿饭你来掌》：纯情绪章，不推进案情，无对手无阴谋。阿绫第一次独立掌一顿饭，她和苏合都尝不出，靠一屋子人的舌头做成。小满第一次浮字，只表达她确信阿绫能做成。章尾：柳婕妤用右手端起一碗汤走三步，没有洒。

93《你若肯说，我今日只带一碗饭》：苏合决定去见勘问后期的何崇，先按规定申请探视；韦只按手续办事，不帮不拦。阶段结果：获准三日后见面。章尾：探视簿上，苏合之前已有一个没有姓名的访客记录。

94《这张样册，早在下发前就有人用过》：陆清衡以旧纸、水印、格线证明统一格式泄露。她吃苏合所做食物后浮字，确认自己也察觉异常。阶段结果：泄露发生在“上意”抵达尚食局之前。章尾：样册纸来自勘问后院。

95《何崇，我只问这一个名字》：苏合见何崇，拿现有证据逐项堵住其推辞，只问签令者姓名。何崇不说，但承认对方仍能看见勘问记录。他答应三日后给苏合一样东西，不承诺名字。章尾：他指定下一顿要吃苏合亲手做的最普通的面。

96《这一次，我不怕了》：苏合给何崇做一碗普通汤面。何崇仍不说名字，把二十年前北地驿站食单交给她；食单上有苏蕙的字。何崇吃面后此生唯一一次浮字，表达他决定这次不再怕，但绝不直接点名。章尾：他让苏合走时，把面吃得一滴不剩，并拒绝把食单收回。

### 第三段：何崇之死与制度反击（97—104）

97《三日后，他死在勘问后院》：苏合按约再去，得知何崇被定为病故。她要求验死亡时辰、饭食、值守和遗物，均被“病故”挡回。阶段结果：确认他是当夜独自死去，唯一知道名字的活口消失。章尾：死亡记录的归档时辰早于报死时辰。

98《病故两个字，写得比人死得快》：苏合、裴宴与韦围绕何崇死亡记录正面交锋；没有翻案、没有找出凶手，所有手续都完整。苏合遭遇本卷最重失败：线被从另一头封死。章尾：唯一未被收走的是他交出的北地食单，因为档里从未记过它。

99《这张食单，为什么有我娘的字》：苏合低谷后重看食单，不靠新证人突破，只从菜名、驿站印和苏蕙改写的分量确认她曾去北地。章尾：食单日期在苏蕙“自请离宫”之后七日。

100《少一页，整本册子也不能算清白》：灶册系统因换页问题面临废止。苏合不护自己的做法，提出页码、骑缝、交接人、原册与誊本分置的改法；韦反对由掌灶私留原册。阶段结果：双方形成双份互证方案。章尾：第一批双份册里，只有苏合的页数对不上。

101《韦典膳，您也在别人的册子里》：苏合让韦亲自走完调册链，证明有人借她的“上意”与统一格式定向取苏合旧册。韦吃苏合所做食物后第二次浮字，确认她意识到自己被利用。她仍不倒向苏合，只撤回有漏洞的单方收册令。章尾：调册目标不是旧案页，而是苏合记录“借菜看字”次数的页码。

102《册子归尚食局，证据归每一个签名的人》：韦与苏合公开重订制度：统一格式和归档保留，签押人各持短凭，调册须留痕，原页不得无痕替换。有人试图以“上意”压下，韦要求书面署名。阶段结果：灶册成为尚食局明规矩。章尾：书面上意无人肯署名。

103《这一等，不是谁赏给我的》：尚食局依据公开记录核算苏合实际掌灶、救灶与制度贡献，升她为一等女厨。她拒绝私人提拔，但接受制度结果。阿绫继续掌饭，柳婕妤能端碗，小满仍会写错但错误必须留痕。章尾：升等交接清点时发现苏合私册某页纸纹比相邻页薄。

104《那只手要找的不是案子，是我》：苏合检查私册，确认一页曾被拆下抄录后放回。被抄的不是停料、幽禁或苏蕙，而是每一次“借菜看字”的日期、对象与次数。卷末状态：灶册保住；苏合以制度升一等；何崇已死；手持北地食单；苏合与阿绫味觉未恢复；柳婕妤能端一碗走三步。最后落点：那只手已经知道食心的使用轨迹，它在意的不是案子，是苏合。

## 六、文风与交付

- 延续第59—80章的白描、短对话、具体物件和灶上动作；避免总结式议论和现代制度术语堆叠。
- 韦典膳语言简洁准确，不阴笑、不威胁、不收买；她的压迫感来自把正确规则执行到底。
- 何崇死亡不得写成伏法或报应，不给凶手破绽；第97—98章允许减少笑点，保留失败重量。
- 正文不出现章纲、自检标签、写作规则或“本章”说明。
