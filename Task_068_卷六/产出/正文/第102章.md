# 第一百零二章 册子归尚食局，证据归每一个签名的人

撤下单方收册令的第二日，三张长案刚搬到灶院，外院便来领急膳。

十二名修沟的杂役临时留值，原处已经散饭。来人拿着管事签过的急条，要一锅热面，吃完还得赶在雨前把沟盖合上。

韦典膳将管事的押记核过，叫众人让出灶口。原册、浅黄誊本、两指宽的短凭仍分摆三案，掌灶、复味、送膳的人都在。

“今日这锅，照新规做。”她说。

苏合先把水坐上火。小满抱来面袋，刚想解绳，阿绫却发现领来的临时页没有号。

书吏把页塞进册尾：“先做，散灶再编。”

“那这袋面记在哪页？”苏合按住袋口。

锅底细泡已起。阿绫翻到原册末页，三十一。她将临时页当场编作三十二，浅黄纸也写同号，两边各接在旧册后，写明日期、末灶与急由。

送膳老宫人正要按印，书吏把整页推给她：“一道押省事，出膳时不必再等您。”

她缩回手：“饭还没见着，我押什么？”

韦典膳把内容栏遮住，只露出册缝：“现在只认添了一页。饭熟了，再签亲眼见过的。”

苏合、复味女厨与老宫人分押三处，位置错开。阿绫举起两册相核，骑缝无断，空处划线封住。面袋这才解开，小满称面，苏合和面，水分两次入盆。

她揉到面团压下能回起，盖湿布稍醒。小满趁这会儿把两册一并抱往长案，档吏已经张开同一只收册匣。

阿绫伸手接回浅黄册。

“都在一处，好抄。”档吏道。

“原册在案上记，誊本在灶边记。写完当面合看。”韦典膳指向两个执笔的人，“散灶只收白册。”

小满来回看两只手：“我报一遍，还是两遍？”

“报到两边都听清。”

“那我的嘴该领两份饭。”

钱三娘把面盆推到她面前：“先叫你的手挣出第一份。”

苏合擀开面团，刀下切成窄片，搭在撒过干粉的竹箅上。她提起一片，面身垂弯不黏，便叫小满报入锅数。两处执笔各记，谁也没拿另一册照抄。

青菜洗净，沥水，盐分称。苏合先将一份盐化进锅里，再把面片沿锅边抖入，长筷拨散。锅里翻上白沫，她撤粗柴，留细火，不让面汤扑出锅沿。

小满擦手来领称料短凭，笔一快，写了昨日的日子。她抬起湿袖要擦，阿绫将袖口挡回去。

“横划一线，在旁边重写。今日的错留在今日。”

钱三娘探头：“她这一张比旁人的值钱。”

“哪里值钱？”

“字多。”

面片浮起，苏合挑一片放在木勺上，看它卷边垂落，又用筷背拨过最厚处。复味女厨尝过，报中心已透，盐轻两分。第二人另尝，也报两分。

阿绫称盐递来。苏合下盐、推匀，再放青菜，叶色转亮便离火。两名复味人各换净勺尝过，老宫人也另尝一匙，三人都报盐足，各落了签。

送膳老宫人备好了十二只碗，见锅已离灶，才在离火一栏按下印。

书吏把她的短凭与其余几张一并叠起：“替您收着。”

老宫人没有放手：“这上头哪一个是三十二？”

书吏指过字，她仍认不出。苏合让他剪三道浅口、扎两点针眼，当面与页码对过。老宫人摸了一遍，把短凭叠进自己袖内。

“如今再说我签了哪一页，得先让我摸摸。”

其余签押人也各拿回自己的凭。小满先前给众人备的一只大凭袋空了，只能拿来装尺。

“这么大的袋，只装一把？”

“你若再把别人的凭收进去，”钱三娘道，“袋子得比料房大。”

两处执笔逐项报数：面、水、盐、入锅、复味、离火，一项项相合。白册先合拢，交膳栏仍空着；浅黄册回到灶案，等最后的送出时刻。

十二碗才盛到一半，前灶的人来借今日原册，想照这锅面配下一轮料。

档吏已把原册递出，来人夹在腋下便走。

“去哪口灶？”韦典膳叫住她。

“前灶。就看一眼。”

“留名、留时刻。”

来人指着案上的调阅簿：“都写了，还写封套？”

“掌簿和掌封套，是两个人。”

苏合手里仍盛着面，往旁边让了一寸。前灶来人只得退回，领有号木签，写明去处、时辰与经手人。封套另一侧由掌封人记，谁也没拆出单页递走。

老宫人将第九碗端进盒里，袖中的短凭露出一道剪口。

“我签过的饭还没出门，纸倒先会跑了。”

前灶来人核过分量，很快将原册送回。档吏先数页，掌封人再验三处骑缝与页序、污痕，销去木签；借出、归还两个时刻都留在封套上。原册暂留收册案，浅黄册始终在灶边。

最后三碗盛齐，十二人领到的都是热面。急膳来人按下接膳印，带走自己的短条，没有把灶边那册也抱走。

交膳时刻记入两册，当面再核一遍。白册封好入档，浅黄册留灶，短凭各归其手，没有一张随册锁走。

“忙起来还要这样？”前灶掌厨问。

苏合抬起空勺：“方才已经做过了。”

韦典膳叫书吏把四项誊到木板上：双份分置，编号与三处骑缝，本人持短凭，调册留痕。急膳临时页当场编号，缺签处照旧封空，后来人只补当时实情，不补原签。

午后，木板钉在院门旁。老宫人拿自己短凭试了试新设的凭袋，嫌袋口窄。阿绫替她放宽半寸，每人的袋仍由各人落锁。

木板刚钉稳，一名内侍从外头进来。他没有报姓名，只把一张无款纸递给韦典膳：“上意，何崇旧案相关灶册仍照原令封收，不发短凭，不记调阅。”

院里的人声停了。

韦典膳接过纸，从头看到尾：“谁传的？”

内侍道：“上头。”

“哪一处上头？”

“典膳照办便是。”

“请来人在纸上署名，或请发令处盖印。”

内侍皱眉：“这是上意。”

“尚食局今日立明规。要破例，也写成明令。”韦典膳把纸放回他手中，“不必写缘由，只写谁令、谁传、何时收册。”

“你敢挡？”

“我不挡。署名便办。”

内侍把声音压低：“上头的事，留了名字，反而叫下面的人难做。典膳初来，不必事事较真。”

“我到这里，就是把每一笔较真。”

“若耽误查案呢？”

“写明急调，可先取册，半个时辰内补交令；不许补签，只许补记。谁急调，谁留名。”

“若名字不能留？”

“那便没有这道令。”

那内侍站在木板前，手指捏皱了纸边。他看过韦典膳，又看三张案边等着领短凭的人，最后把无款纸折回袖中。

“我回去请示。”

“书吏，记。”韦典膳道，“今日未正，无款调册纸一张，来人拒绝留名，原纸自行带回。”

书吏当众落笔。送膳老宫人摸着自己短凭上的剪口，管库女厨把原册封套重新压紧。没有人追那名内侍，也没有人问他从哪扇门来。

册子仍归尚食局。

可从这日起，证据不再只锁在尚食局的一只匣里。每一个签过名、按过印、摸过剪口的人，手里都有一小片。

直到傍晚，那张书面上意也没有人肯署名送回。
