# 第一百章 少一页，整本册子也不能算清白

尚食局把换过页的灶册摆了满满一案。

送膳老宫人认出的折角在左，三份真签拼成的假页在右。再往后，是三口误火却早写好出锅时辰的记录，还有那口数对、锅口不对的坏饭。

韦典膳站在案后：“旧制有漏洞，今日议的是停用统一册。”

屋里立刻有人应声。

“早该停。以前各灶各记，也没闹出这么多事。”

“签一道等一道，饭都凉了。”

“一百二十口锅写成一样，出了错反倒找不到人。”

小满在门边小声道：“当初叫交册的是他们，如今叫烧册的也是他们。嘴比灶门好使，往哪边吹，火就往哪边倒。”

钱三娘靠着门框：“灶门还得添柴。他们不用。”

韦典膳抬眼，两个人一齐站直。

苏合把一本统一册拿到自己面前：“不能停。”

方才说话的人都看过来。

前灶掌厨道：“你的原册被调走最多，假页也是从你这套规矩里出的。你还护着它？”

“我不护。”

“那你说不能停？”

“册子记错了，查册子。页被换了，查页。不能因为有人在秤上动手脚，往后便不称米。”

韦典膳问：“你要怎么改？”

苏合把册子翻到换页处：“每页先编号。今日开灶前领了多少页，写明起止；废页不能撕，划掉，留在原位。”

管库女厨道：“编号也能仿。”

“所以装订后加骑缝押。页与页相接处，各压半个印。换一页，印便断。”

“印也有人能拿。”

“不用一枚印。掌灶、复味、送膳各押一处，三处不排成直线。”

前灶掌厨冷笑：“一锅饭原本等三个人，如今还要等三个人画花？”

“开灶前押空册，不在出锅时等。”

“空册预押，不正是让人添字？”陆清衡在旁问。

苏合道：“只押页数，不押内容。页首写日子与灶号，空处横线封死。出锅后各签自己那一栏。”

屋里的人安静一点。书吏提笔，把她说的几项记下。

韦典膳却道：“编号、骑缝可以。原册仍须统一归档，不得留在掌灶手中。”

“原册与誊本分置。”

“谁留原册？”

“掌灶。”

“不行。”韦典膳答得没有停顿，“册归尚食局，不归掌灶的人。掌灶私留，外人换不了，掌灶自己能换。”

“全收进一只匣，拿匣的人能一起换。”

“所以有交接封签。”

“那张换过的页，封签也在。”

“那是交接后换页，不是收档本身错。”

“若原册和誊本不在一处，换一边，另一边还能对。”

韦典膳看着苏合：“你还是要把证据留在自己手里。”

“我要把两份东西放在两只手里。”

“凭什么其中一只必须是掌灶的手？”

“因为她在灶前，知道这一页原来是什么样。”

“也因为她最知道该改哪里。”

两人的声音都不高，案边却没人再插话。

苏合拿起那张拼了三日真签的假页：“这页上的名字都是真的。若只问签名的人，他们只会说这是自己的押。可送膳老宫人记得折角，管库女厨记得油点，装订的人记得线从哪边穿。证不在一只手里，才没被这一页一并骗过去。”

韦典膳道：“所以签押人各留短凭，不必由掌灶留整本原册。”

“短凭只记自己一栏，仍看不见全页。”

“誊本可以给掌灶。”

“誊错了呢？”

“掌灶当场核对。”

“核过以后被换呢？”

“调阅留痕。”

“留痕被换呢？”

前灶掌厨终于忍不住：“照你这样问，纸匠还能在纸浆里换！”

钱三娘点头：“那得先查他有没有吃饭。饿着肚子的人，什么都干得出来。”

几个人想笑，看见案上的假页，又把笑压了回去。

韦典膳用指尖点了点案面：“世上没有不能动的纸。要紧的是动一张，便在别处留下不合。”

“那就分两处。”苏合说。

“原册归档房，誊本留各灶。每日收册前，当众逐页核对页码、骑缝、污痕、签押。誊本由另一名书吏写，掌灶核，不得由掌灶自己抄。调原册另记短条，调誊本也另记，不能同一人同日取走两份。”

苏合问：“少一页怎么办？”

“当日停收，查清再封。”

“整本作废？”

“不作废。少一页，整本便不能算清白；哪几页核得清，仍是哪几页的证。”

韦典膳让书吏拿十张废纸，当场试一遍。原册留白，誊本浅黄，三个人各在骑缝上压半枚押。小满趁众人转身，把第四页抽出来，换进一张同样大小的纸。

“你倒很熟练。”钱三娘道。

“我这是替坏人试。”

“坏人谢谢你。”

页码表面连着，第一处骑缝也勉强拼得上，到了第二处便错开半粒米宽。书吏再去查短凭，第四页两名签押人手里的页码都在，新页上却少一个针点。

韦典膳把试页举给众人看：“不是叫人从此换不了。是他每多动一处，便要多骗过一处。”

苏合道：“还要记原有污痕。油点、折角、火星孔，都写在交接栏。”

“写得下便写，写不下画位置。”韦典膳叫书吏把这一项补进去。

苏合看了她一会儿：“加一条。每个签押人各持短凭，只写日期、灶号、页码。内容不抄，免得再造一本散册。”

韦典膳点头：“可以。”

这不是谁说服了谁。原册仍不归掌灶，苏合没有拿回自己最想留的东西；尚食局也不能再把两份册锁进同一只匣。

书吏当场画了新页样。页首编号，左边三处骑缝位，末尾多出交册人与收册人。原册用白纸，誊本用浅黄纸，短凭只裁两指宽。

午后，第一批双份册发到各灶。

阿绫在冷宫小灶逐页报数，小满在旁边核：“一、二、三、五——”

“四呢？”

“我心里数了。”

“纸上没有心里那一页。”

小满只好从头再来。

前灶、末灶、点心房的页数都对。封签人把起止号写上短条，一本本收入木匣。

轮到苏合的册，阿绫数完原册，又数誊本。

“原册二十四页。”

“誊本呢？”韦典膳问。

阿绫重新数了一次。

“二十五页。”

满屋的人都望向苏合。

第一批双份册里，只有她的页数对不上。
