# 第九十七章 三日后，他死在勘问后院

第三日天还没亮，苏合便把北地食单折进衣襟。

那张纸是何崇三日前交给她的。纸上有苏蕙的字，边角还沾着一点面汤。他把一整碗面吃得干干净净，临走时只说，三日后再来。

苏合按他说的日子来了。

勘问后院的门却没有开。

值守换了人，腰间挂着外廷的黑木牌。他看过苏合的探视凭，又把凭退回来：“今日不能探。”

“凭上写的是今日。”

“人昨夜病故了。”

院墙里正有人抬出一副窄木床。床上盖着灰布，四角压得很平，没有露出一只手。

苏合站在门槛外，没有追那副床。她问：“几时死的？”

值守道：“病故。”

“我问时辰。”

“记录上有。”

“谁发现的？”

“值夜人。”

“哪一个值夜人？”

值守把门往里带了一寸：“苏女厨，后院不是灶房。病故二字，已经写明。”

曹德安从廊下赶来。他一夜都在旧卷房核册，眼下发青，手里还捏着半块没吃的冷饼。看见灰布床，他脚步顿住，饼从指间掉到地上。

他没有去捡。

“何掌印——”

“已经不是掌印了。”值守纠正。

曹德安望了他一眼：“我叫了二十年，一时改不过来。”

“那便慢慢改。”

苏合把探视凭按在门案上：“昨夜送过什么饭？”

“后院例饭。”

“什么饭，谁送，何时送，食盒何时收回？”

“病故与饭无涉。”

“有没有关涉，查过才知道。”

值守不再答，只叫书吏取来一张新纸。纸上写着何崇姓名，下面两字墨色很深：病故。再下是入院时辰、问话停歇时辰、夜间落锁、卯时验看，栏栏齐全，值守、医工、书吏各有签押。

苏合看完第一遍，又从头看第二遍。

“夜饭呢？”

书吏点了点纸角：“食毕，无异。”

“剩了多少？”

“后院例饭不称剩食。”

“碗呢？”

“洗了。”

“床上的人，我能不能看一眼？”

值守的手压住门案：“遗体已经覆验，非亲属不得近前。”

“不近前。只看他昨夜穿的衣裳，看手上有没有抓过门、碰过碗。”

“验单写着外观无伤。”

“验单写的是医工看见的。我也有眼睛。”

“你是女厨，不是仵作。”

“他最后吃的是我做的面。”

“那是三日前。昨日例饭与你无关。”

灰布床在侧门外转过墙角，连最后一点木脚也看不见了。苏合没有得到第二眼。

“饭是谁做的？”

“外灶按例送来。”

“我去查外灶。”

值守伸手拦住她：“此人已经病故。无验食令，你不能以勘问人的名义扣外灶册。”

苏合抬头：“那就给我验食令。”

“谁来给？”

“勘官。”

“勘官已经看过病故记录。”

一句话绕了一圈，又回到纸上那两个字。

裴宴来时，窄木床已经出了侧门。他只带了一名随从，进门前把宫籍牌交给值守：“我要见勘官。”

值守躬身，却仍没有让路：“殿下，此案今日停问，勘官在正堂议卷。后院有后院的规矩。”

“人死了，规矩便只剩关门？”

“人病故，才更不能乱。”

裴宴的手按在门案边沿。苏合看了他一眼：“别闯。”

他没有替她开这扇门，只把手收回：“你要查什么？”

“死亡时辰、昨夜饭食、值守轮次、随身遗物。”

值守道：“时辰已记，饭食无异，值守签押齐全，遗物已经清点入封。”

“让我看清单。”

“非亲非故，无权领看。”

曹德安弯腰捡起冷饼，掸了两下灰。那灰嵌进饼裂里，怎么也掸不净。

“我算不算故旧？”他问。

“不算亲属。”

“我替他办了二十年事。”

“更不算亲属。”

曹德安把饼攥回手心，低声笑了一下：“活着时算他的人，死了倒什么都不算。”

他转向苏合：“昨夜戌末我还从这条廊下过。院门落着锁，窗里没有灯，也没有叫医工的动静。”

值守立刻道：“你在旧卷房当值，不得私议后院。”

“我没议。我只说我没听见。”

“没听见不能作证。”

“那谁听见了？”苏合问。

无人回答。

书吏把病故记录往回抽。苏合的手还压在纸角，两人隔着一张薄纸僵了一会儿。

“让我抄时辰。”她说。

“记录已经归档，不得抄录。”

“刚才还在我眼前。”

“给你看过，已经是通融。”

苏合松开手。纸角从她指下弹回去，半点折痕也没留下。

她在廊下等到午后。勘官从正堂出来，只答何崇当夜独处，卯初由值守发现，医工验看后定作急病。苏合问急的是什么病，医工答脉绝气断，旧疾猝发；问旧疾何在，入院验身簿上写着心悸、咳喘、夜不能寐。每一项都能对上。

她又问遗物。勘官说衣一身，旧帕一方，木梳一把，散钱七枚，已经封存。没有信，没有供词，也没有答应三日后要说的话。

“昨夜可有人进去？”

“落锁后无人开门。”

“他叫过人吗？”

“无人听见。”

“所以他独自死的。”

勘官看着她：“记录如此。”

苏合让他在答复上写明“当夜独处”。勘官起先不肯，说值守就在门外，不能叫无人看管。她便改问：“落锁后有没有人进屋？”勘官答没有。苏合指着书吏的笔：“这一句能不能记？”

书吏最终写下：落锁后无人入室，卯初开门，何崇已无气息。

这是她一日里争到的唯一一句话。它证明不了怎么死，只把那扇整夜没有开启的门留在纸上。

苏合走出外廷时，天色已经发白。她今日来得太早，等得太久，竟像又过了一夜。

曹德安还站在石阶下，手里那半块饼始终没有吃。他问：“他最后给你的东西，可收好了？”

苏合按住衣襟里的食单：“收好了。”

“那便别再拿出来。”

她没有应。

门内有人抱着卷匣经过。最上面正是方才那张病故记录，纸背露出一行收档小字。苏合只看见一眼，便追上两步：“等等。”

抱匣人停下。

“给我看背面的时辰。”

“已经归档。”

“报死是卯初，医工验看在卯正，是不是？”

“记录上写得明白。”

“那为什么收档是寅末？”

抱匣人把纸往匣中一压，合上木盖：“归档只管收纸，不管人几时死。”

木匣扣紧。

何崇的死亡记录，在他被报死以前，已经归了档。
