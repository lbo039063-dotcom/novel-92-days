# 第七十四章 我记得那碗是烫的

苏合拿着裴宴的宫籍号，才能调看裴氏母族被逐那日的膳档。

可这块铜牌起初不在她手里。

“停料令到此为止。”裴宴站在西偏殿书案后，“不要再查。”

苏合把四张纸排到他面前。前两张属于二十年前：一张是那味料的退料记录，一张是苏蕙离宫的日期，前后紧挨着。后两张属于十三年前：一张是裴宴的幽禁令，一张是裴氏母族二十七人的迁逐令，落在同一天。

“两组事，相隔七年。每一组的前后都接得太紧。”

“我看见了。”

“苏蕙在那之后离宫。十三年后，你被幽禁，母族同日被逐。两道令都有何崇经手，真正落笔的却不只他。”

“我也看见了。”

裴宴逐页指出她手里缺的东西。二十年前的退料单只有名字，没有来处，停用回执只剩半张，签名不全；十三年前虽有两份幽禁令，母族迁出单上也有何崇的印，却没有写为何两道命令落在同一天。

“三条线摆在一张桌上，不等于它们已经打成一个结。”

“所以才要找剩下的纸。”

“也可能根本没有纸。”

“那便找记得的人。”

“二十年了。”

“旧料房的老妇还记得柳婕妤，管库女厨还记得那道令。只要人没全死，总有人记得。”

裴宴道：“记得的人也会怕。”

“怕不是忘。”

“那你为何叫我停？”

裴宴将三张纸合起来，推回她面前：“因为何崇亲自来过末灶。他怕的那个人，到现在还在。”

“所以更要查。”

“所以不能拿你去试那个人会不会动手。”

门外传来一声极轻的木头碰墙声。

小满正把耳朵贴在门缝上，手里还端着一盘没送进去的糕。曹德安从后面捏住她衣领，把她提离门边。

“我在等空盘。”她小声道。

“满盘也能等？”

“殿下吵饿了就会吃，吃完便空。”

“去廊下。”

“让我听完这一句。”

曹德安把她拎远两步。小满还伸着脖子，盘里的糕差点全滑到一边。

屋内，苏合道：“何崇说苏蕙查到这里就走了，还说是他劝的。你信他？”

“我不信他是好人。”

“那便查。”

“正因为他不是好人，他肯来劝你，说明后面的人比他更不愿让这件事见光。”

“苏蕙已经走过一次。我若也停，这两组年月便继续各自压在旧纸里。”

“那就等。”

苏合看着他：“你说什么？”

“等到有把握，等到外廷旧案真正开勘，等到我们知道要防谁。不是今日拿着半张回执往下撞。”

苏合从袖中取出一张调档申请。上头已经写好十三年前的年份与膳档门类，只空着调档人的宫籍号。

“我没有要撞门。我只要看这七日的膳食记录。”

裴宴拿起申请：“你连要查哪七日都算好了。”

“母族迁逐前后三日，加发令当日。”

“外廷档房不会凭一个女厨腰牌开裴氏旧档。”

“所以我来找你。”

“若我不给？”

“我再找别的路。”

裴宴把申请折了一下。纸没有撕，却在空白的宫籍号上压出一道深痕。

“你的母族等得起吗？”

裴宴的脸色沉了：“不要拿他们逼我。”

“我没有逼你。二十七个人被逐到北地，名册断了十三年。冷宫料罐封存与他们的迁出令落在同一天，你却要等。”

“正因为他们已经没了续记，我不能让你也变成一行断掉的名字。”

“那是我的名字。”

“可你出事，不只你一个人承担。”

“柳婕妤受伤时，你没有叫我停。”

“所以她的右手到现在还端不稳碗！”

声音落下，两个人都静了一瞬。

门外小满也不伸脖子了。曹德安把她手里的糕盘端走，放到廊柱上。

苏合问：“你后悔查幽禁令？”

“不后悔。”

“那你后悔什么？”

“后悔我每次都以为，只要再快一步，身边的人便不会受伤。”裴宴道，“可柳婕妤的手已经伤了，曹德安也回不了内侍省。下一次是谁？”

“你要我因为不知道下一次是谁，便什么都不做？”

“我要你先活着。”

“活着守两口灶，等别人再来掀锅？”

“至少那两口灶现在有牌。”

“牌是人刻的，令也是人写的。昨日能提前盖印，明日便能写一行把牌收走。”

裴宴按在书案上的手收紧。铜制宫籍牌就在他掌边，边缘硌得指节发白。

“你什么都不怕？”他问。

“怕。”

“怕什么？”

“怕我娘留下的味道彻底没了，怕我查到最后，连她为什么走都不知道。也怕你母族那二十七个人，只剩一张迁出单。”

“那就别把自己也添进去。”

“裴宴，你被关十三年，不是为了出来以后学会怎样把门从外头锁上。”

这句话落得太重。

裴宴看了她很久，忽然把桌上的三张纸全扫到一边。纸页擦过砚台，边角染上一道墨。

“出去。”他说。

苏合没有捡纸：“好。”

她转身便走。门一开，小满来不及躲，整个人往里栽。曹德安揪住她后领，才没让她脸先着地。

“吵完了？”小满扶着门框问。

苏合从她身边过去：“糕给他。”

“殿下看起来不饿。”

“那你吃。”

小满抱起糕盘要追，又回头看裴宴：“真的听完了？要不你们再补一句，我可以等。”

曹德安把她连人带盘拎走：“再听，耳朵扣半个月饭钱。”

“耳朵吃什么饭？”

“你的。”

小满立刻捂住两边耳朵。

苏合走到院门时，身后响起脚步。她没有回头，只听见一声轻响，有东西落进她方才放纸的木匣里。

裴宴把自己的宫籍牌放了进去。

“用我的宫籍号，可以调看母族迁出前七日的膳档。”他说，“只看档，不碰原令。”

苏合转过身：“你不是让我出去？”

“你已经出去了。”

“这算什么？”

“算我没能把门锁上。”

他没有送她，只站在书房门内。两个人隔着一段院子，谁也没有说方才那场争执已经过去。

苏合取出宫籍牌，次日去了外廷档房。

裴氏母族离京前七日的膳档残缺，只剩两页。冷宫料罐没有另记，幽禁令也没有附在膳档里。最后一页却列着裴宴生母当日用过的膳食：糖一碟，汤一碗。

裴宴后来也来了。他看着那一行，手指在“汤”字上停住。

苏合问：“你见过？”

“母亲掰糖那天，桌上就有一碗汤。”

“什么味道？”

裴宴道：“味道我记不得，但我记得那碗是烫的。”
