# 第六十六章 印是昨天盖的

尚食局公议设在前灶长案前。

苏合到时，案上已经摆好记录纸。何崇坐在客位，陆清衡坐在正中，两旁是一等女厨、管库与送膳内官。

门外挤满了人。

吴内侍当众念出议题：“掌灶者当能定味。苏合失咸失甜，凡出锅皆赖旁人试尝，不足掌末灶。今日公议，暂收膳灶牌。”

一句话落下，所有人都看向苏合。

何崇没有说“你尝不出”。他只将那四个字换成了尚食局的规矩，摆在一张将要归档的纸上。

一名老掌厨道：“大宴虽有复味，掌厨自己也要尝。若连淡咸都不知，出了差错，谁担？”

“公议不是考灶。”另一名掌厨道，“今日做成一锅，也不能保明日。”

苏合把何崇送宴的条子放到案上，背面四字朝下：“既然议的是我凭什么掌灶，总得先看我怎么掌。若只凭一句尝不出便收牌，这张记录昨日就能写。”

何崇抬眼看她：“你以为一道菜能改规矩？”

“先看菜。”

陆清衡让记录人另开一栏，写“当场验灶”。两名原本只来听议的一等女厨被点作核料，送膳房也推一名老内官看时。

吴内侍道：“都是与你共事的人，难免偏帮。”

陆清衡又从门外随手点了一名刚来领食盒的宫人：“你看秤。认识苏合吗？”

那宫人摇头：“只吃过她的粥。”

“吃过，不算没关系；只吃过，不算有交情。”

“我担。”苏合道。

“你凭什么担？”

“做一道菜。”

吴内侍笑了：“今日议的是你不能定味，你还要拿菜堵人的嘴？”

“清汤。”

前灶里安静了一瞬。

清汤看着最淡，做起来却最藏不住错。骨血去不净便浑，火大一分便翻白，澄汤稍迟便散。它不靠重盐厚酱遮味，正是最不能靠一口尝来补救的菜。

陆清衡道：“准。”

鸡骨、瘦肉、清水当场过秤。苏合把每一样的数报给记录人，自己复述一遍，再让管库女厨对秤。

老掌厨临时换了一只锅：“你平日那口锅做惯了，不能算。”

新锅口宽半寸，锅底更厚。苏合先倒一升水，记下从冷水到锅边起泡所用的刻数，再把测试的水舀净。

“你在拖时辰？”吴内侍问。

“量锅。”

“锅就是锅。”

“厚一分，退火便晚一分。”

苏合把新锅的起泡刻写在短纸上，原定第二刻退火，改为第二刻后半。老掌厨亲手摸过锅底，没再说话。

“鸡骨三斤六，瘦肉一斤二，水八升。”

管库女厨看秤：“对。”

“盐三钱，分两次。第一回一钱八，第二回一钱二。”

小满在门外举手：“我能复核第二回。”

吴内侍道：“你不在公议名册。”

“加个名字很快。”

“你连生米都说香。”

“生米本来就香！”

门外响起一阵笑。陆清衡让人把小满拖到门槛外：“第三人由送膳房出。”

“那我第四。”

“没有第四。”

“公议也太省碗了。”

苏合没有碰盐。管库女厨称第一份，陆清衡看着下锅；第二份由送膳老宫人称，一等女厨复秤。

汤将开时，苏合撤去一半硬炭，只留碎炭围住火眼。浮沫起到锅边，她用细网一遍遍撇。瘦肉剁泥，以冷水调开，分三次入锅澄汤。

第一遍肉泥沉下，汤色仍有些灰。门外有人低声说要坏，吴内侍也朝记录人看了一眼。

苏合没有补任何料，只把锅向外挪一寸。水面不再翻，细沫慢慢聚到中央。她用网捞净，再下第二遍肉泥。

管库女厨守着盐秤，手心出了汗：“一钱二已经称好。”

“先不下。再等半刻。”

“册上的时辰到了。”

“锅换了。”

半刻后，汤从灰白转清。第二份盐落下，送膳老宫人复秤，纸上压了两个人的指印。

老掌厨忽然问：“若此刻入口偏淡呢？”

“不添。”

“偏咸呢？”

“这锅撤下，查秤。”

“不凭口救？”

“清汤临出锅再追盐，只会一碗一个味。”

每一次都报刻。

“第一刻，退火。”

“第二刻，肉泥第一次下。”

“相隔半刻，第二次。”

记录人的笔跟着她的话走。门外的人不再议论，只盯着锅里由浑转清的汤。

后灶忽然传来小满一声喊：“苏合！锅焦了！”

末灶还煨着一锅宫人午食。苏合抬眼，看见门边已有一缕灰烟钻进来。

她盯着澄到第三遍的汤，没有回头。

阿绫飞快跑去撤锅。苏合只看了一眼那缕烟，便把末灶火位记在手边短纸上：“午食锅，第三刻，撤火迟。另换人看。”

吴内侍道：“锅都煨焦了才有人喊，还谈掌灶？”

“所以那锅有人看。”

“若小满不喊呢？”

“今日她在名册上。”

苏合把清汤的锅盖揭开。澄过三次的汤已透亮，勺子沉到底，仍能看清勺沿。

三只白碗摆上长案。

陆清衡先尝，老掌厨第二，送膳内官第三。三人各自写下结果，折起，交给记录人。

“清。”

“鲜。”

“盐正好。”

记录人展开三张纸。三人的“正好”写法不同，落笔也分先后，不可能临时串过。

门外最前头的送膳宫人被准许尝第四碗。他喝完没说话，后头立刻催：“到底如何？”

他把空碗倒过来：“没了。”

“谁问你有没有！”

“想知道自己等下一碗。”

人群又往前挤半步，门槛都被踩住。陆清衡让人把余汤分成小盏，一人只能一口。尝过的人退到旁边，却不走，盯着公议案上的牌。

老掌厨又喝一口，迟迟没有放下勺。门外送膳宫人伸长脖子，后头的人问前头如何，前头只摇头，让他自己挤近看。

吴内侍道：“三个人说好，也不能证明每次都好。”

苏合把今日从称料到收火的短纸放在案上：“所以每次都记。”

“掌灶靠人复核，终究不是本事。”

“汤在这里。”

她只说了四个字。

门外围观的人一下议论开。有人说那汤比前灶往日还清，有人问能不能分剩下的半锅，小满在人后喊自己虽不在名册，也可以负责洗碗。

公议不能再以“不能定味”为由收牌。

陆清衡当场宣布：“末灶仍由苏合掌。”

小满在门外跳起来，脑袋撞上门框，又捂着头假装自己只是看梁。

何崇端坐不动：“既然诸位认她的办法，便写进记录。往后出了错，也好有据可查。”

记录人重新落笔。

“末灶定味需三人复核。”

苏合看着那一行字。她的牌保住了，末灶也没有停。可从今日起，她每做一锅菜，都要先找到三个人的舌头，留下三个人的名字。

老掌厨道：“这是为了稳妥。”

何崇道：“自然。”

公议散后，记录纸送去档房归档。陆清衡叫人先核页码与印，免得日后又有人说这张纸来路不明。

档吏将纸翻到末页，忽然“咦”了一声。

“怎么？”陆清衡问。

“归档印已经盖过了。”

鲜红方印落在“末灶定味需三人复核”下方，印泥已经干透。档吏拿今日刚开的印盒比过，颜色不同。

他刮了一点印边，又翻出值印簿。

“这枚印，是昨天盖的。”
