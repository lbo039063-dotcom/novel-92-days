## 一、逐章事件与章末状态

| 章 | 已落地事件 | 章末状态 / 新信息 |
|---|---|---|
| 59 | 苏合持双面膳灶牌和两处膳数、押记领米炭；领米房以“一人不能领两处”为由拒发，苏合按实际膳数核销出处，最终分别领到末灶与冷宫小灶的米炭。 | 十三年前的领米总簿曾有一行“冷宫小灶，领陈米三升，碎炭五斤”，名字与整行后来被重墨划掉。 |
| 60 | 何崇下条子让苏合独掌一百二十份小宴；苏合核算灶、人手与两口灶的日常膳食后，只接三十份，余下九十份退回。 | 何崇在条子背面写下“你尝不出”。 |
| 61 | 尚食局有人当众要求苏合尝肉羹自证；苏合不尝，报出盐三钱二、下盐时点和火位，由三人独立复味，数字与实际相合。陆清衡随后交给她一本不靠掌灶者口尝、改用记数和复核的旧册。 | 旧册写册人是苏蕙；册中有“口尝只得一时，数可留后人”。 |
| 62 | 苏合照旧册做酸笋鸡汤，因把酸味的空缺当成淡而多加半勺盐，小满又漏报退火，第一锅分量对、火候错，整锅作废；她认败并如实记录，另起六份小锅，由多人分工复核后做成。 | 旧册最后一页的撕口颜色新、边缘利，不是二十年前自然遗失，而是近期被撕。 |
| 63 | 三十份小宴全部做成。何崇当众提出把苏合升为一等女厨，苏合以自己只做成三十份、仍只配二等之责为由辞升，并把苏蕙二十年前的晋升册与今日新册并排示众。 | 何崇说：“她当年也这么说。” |
| 64 | 柳婕妤坚持亲手做饭，旧灶过高、大锅难握，险些泼水再伤右手；苏合按身量、手臂活动和锅重改出小锅、矮灶、内移锅耳、木挡、踏板和短火钳，柳婕妤得以自行煮粥。 | 柳婕妤认出二十年前、自己尚未入冷宫时，苏蕙曾在其旧居小厨房给她改过同样的灶。 |
| 65 | 冯内侍等七名旧同僚以“何崇救命、养了二十年”堵曹德安讨债。曹德安逐年列出替何崇办过的事、挨过的伤与所得住处、靴、药，算到第二十年后说“够了”。 | 当年杖责名单上，曹德安的名字与“杖五十”是何崇后来添上，又由何崇用同一只手划掉。 |
| 66 | 尚食局公议以“尝不出味”为由要收苏合末灶牌。苏合现场用新锅做清汤，称量、报刻、调火、三人复核，汤成，保住末灶。公议同时写入“末灶定味需三人复核”。 | 公议记录的归档印不是当天所盖，而是前一天预盖；同章中苏合未闻到末灶锅焦，靠小满喊才发现。 |
| 67 | 苏合查预盖印的纸与经手时辰，以末灶领炭条、冷宫换桶条及档房领纸记录互证，逼出档房领印、还印记录被合并补写。 | 档房交出一张前一日申末取纸借印的窄条，末尾是陆女史签押；经手人称条子是陆女史给的。 |
| 68 | 苏合当面质问陆清衡。陆承认空白条上的签押是她所留，但取纸借印两行是别人后来添写；交接册和前灶多人证明她在相应时段未离开前灶。陆列出可能接触空白条的十二人。 | 添字笔势与二十年前苏蕙晋升册上压在何崇旁批下的旧痕相像，但不是何崇的手。 |
| 69 | 裴宴在西偏殿正式设六人饭席。司膳处来人以份例和男女规矩阻拦苏合删减九道膳单；裴宴、曹德安据已盖印的细则证明临时设饭的菜品增减由当日掌灶者核定，最终按苏合定下的五道开席。 | 裴宴喝汤后，余下汤面浮字“她今天没问咸淡”；他在膳单末尾添了“疙瘩汤”。 |
| 70 | 苏合按苏蕙旧方做疙瘩汤，让阿绫、曹德安、裴宴、小满分别先尝并记录第一口反应；众人都说像，苏合自己只能辨温度、软硬和做法，尝不到他们所说的味道。 | 柳婕妤说汤“少了一样东西，你娘那碗里有的”。 |
| 71 | 柳婕妤说不出所缺之物的名字，只记得咽下后有一点香。苏合用半只鸡、一碗汤和两小碟腌菜换钱三娘翻旧料底单，找到一味只剩两个字的旧料记录。 | 该料最后一次进货在二十年前；退回三两后次日被整项划去，此后十九年未再入总料目，停货之年正是苏蕙离宫之年。苏合同时无法从三碟同菜中辨出哪碟加过糖。 |
| 72 | 苏合持抄单追问管库女厨。管库女厨交代：二十年前御膳下毒案后三日内封过七种料，六种半年后解禁，只有这一味未恢复；原停用令写“气味辛烈，易掩药味”，原令到库时何崇还只是少监并被挡在库外，后来何崇以自己签押的抄令替换执行，取走原令。 | 领料簿页缝所留的半张原令回执有陌生印和残缺签名，签名不是何崇。 |
| 73 | 何崇独自到末灶索要领料簿或抄单，苏合拒交。何崇承认原停料令不是他签、抄令是他送，也承认害怕签原令的人；他不提供名字，只警告苏合继续查可能走不出宫门。 | 何崇说苏蕙查到这里便走了，并补充“我劝她走的”。 |
| 74 | 苏合把二十年前的停料与苏蕙离宫、十三年前的幽禁与裴氏母族迁逐并置，要求查裴氏母族迁出前后膳档。裴宴认为证据不足且幕后者仍在，要求她停手，两人发生第一次正面争执；裴宴最终把自己的宫籍牌给她，限定只看档、不碰原令。 | 残存膳档记载裴宴生母当日有糖一碟、汤一碗；裴宴记得母亲掰糖那天桌上有汤，味道不记得，只记得汤是烫的。 |
| 75 | 旧料房锈锁木匣中找到一只灰蜡封口的小瓷瓶。苏合先尝针尖量而无味，残料经米浆化开、银片验过未变色，再稀释后由阿绫入口辨味；阿绫尝出料味已经走坏，随即喉阻、发青倒下，经医工救治保住性命。 | 阿绫从此无法辨认盐、糖、苦药、酸梅等味道；医工说二十年前尚食局出现过同样症状。 |
| 76 | 尚食局公议追究残料伤人。苏合承认开瓶、化汤和阿绫在自己面前倒下，同时出示第66章公议记录及多张实际执行短条，指出“三人复核”不能只在需要时算规矩、出事后又只追一个名字。管库女厨等多人作证。 | 苏合主动交出“尚食末灶”主牌；陆清衡拆下并归还“冷宫小灶”薄凭，明确尚食局管不到冷宫这口灶。 |
| 77 | 冷宫小灶熄火两日后，苏合与另一名宫人按相同用料、火候各做一锅粥；碗和锅被换位后，苏合分不出哪碗是自己做的。她没有口头表态，而是新立“冷宫小灶”册，记录用料、时辰、火位、试味意见与签押；小满、柳婕妤、阿绫参与核记。 | 柳婕妤确认二十年前最后一罐该料用灰蜡封口，最后一次使用地点就是眼前的冷宫旧灶。 |
| 78 | 苏合、裴宴、曹德安、小满、柳婕妤拆挖冷宫旧灶。八名无明确所属、没有可核正令的人以走火为名来封灶，曹德安认定不是何崇的人；众人抢在封灶前挖出铁匣，来人当众无法夺匣后撤走。 | 铁匣内有灰蜡封口料罐和一张无签名封存单，写“余料封存冷宫旧灶，不得入局”；单子日期与十三年前幽禁令签发日期完全相同。 |
| 79 | 外廷开勘。勘官以苏合尝不出味、所言只是转述质疑其证言；苏合提交三个月灶册，记录每道菜的分量、刻数、火位，共四十七人、八十三处签押。四十七名相关人证在堂外逐一认签，记录又能与送膳簿、领料簿相合。 | 何崇承认停料令不是他签，拒绝供出签令者，并交出保存二十年的苏蕙字条。 |
| 80 | 苏蕙字条只写：“我不是被你逼走的。我自己走，把这味料带出去。”何崇承认留条为自保，仍不供签令者；外廷收走掌印，令何崇停掌印、移交后院继续勘问，并派人守住旧卷房。阿绫在冷宫小灶负责记数、时辰、火位和试味签押。陆清衡交还末灶牌，并称尚食局已修改公议记录。苏合把末灶牌与冷宫灶牌一起挂起，两口灶继续开火。 | 苏合味觉仍未恢复，不再问咸淡，照数与签押掌灶。外廷誊出的停料令揭去一层旧污后，签名仍有一半糊住；苏合只看清其中一个字，正文未展示该字。 |

## 五、物证与时间线

### 二十年前

- 苏蕙留下的不靠掌灶者口尝、改用分量、刻数、火位与多人复核的旧册；第62章确认最后一页近期被撕。
- 苏蕙晋升册上有何崇旁批，旁批下隐约压着另一道旧痕；该旧痕与第67章窄条的添字笔势相像，但正文未确认执笔人。
- 曹德安的杖责名单：其姓名和“杖五十”为何崇后添，朱线又由何崇亲手划去。
- 御膳下毒案后三日内七种料被封，六种半年后解禁；目标料以“气味辛烈，易掩药味”为由永久停用。何崇送入自己签押的抄令并取走原令。
- 旧领料簿页缝留有原令的半张回执，带陌生印与残缺签名；签名不是何崇。
- 目标料退库三两后被红线整项划去，此后十九年未再出现于总料目；同年苏蕙离宫。
- 苏蕙交给何崇的字条写明她是自己离宫，为把目标料带出去；何崇保存该字条二十年用于自保。
- 旧料房残存小瓷瓶以灰蜡封口；残料经阿绫入口后造成无法辨味的伤害。医工记得二十年前尚食局曾有同样症状，但正文未给出当年患者身份。

### 十三年前

- 领米总簿出现一次“冷宫小灶，领陈米三升，碎炭五斤”，后被重墨划掉，名字难辨。
- 裴宴幽禁令、裴氏母族二十七人迁逐所涉日期，以及冷宫灶下封存单日期落在同一天。
- 裴氏母族迁出前后膳档仅残两页；裴宴生母当日膳食中有糖一碟、汤一碗。裴宴只记得母亲掰糖当日那碗汤是烫的。
- 冷宫旧灶下铁匣中有灰蜡封口料罐和无签名封存单，单上写“余料封存冷宫旧灶，不得入局”。

### 本卷现时

- 第60章三日后的小宴由苏合只接三十份并在第63章完成；何崇借机提出升等，苏合辞升。
- 第66章公议记录纸在公议前一日已盖印；执行文本写入“末灶定味需三人复核”。第67—68章确认陆清衡签过空白条，取纸借印文字为他人添加。
- 第75章阿绫因旧料残液倒下，次日醒来，医工确认舌脉受伤、此后无法辨味。
