# 第146章 锅底多了一钱

第七只菌菇羹刚称完，正殿便来催出菜。

七只汤碗在西案排成一列，碗口都盖着薄瓷盖，席号朝外。第一段送菜人已经扶住木托，只等阿绫翻最后一根碗筹。

她没有翻。

“锅底。”阿绫说。

掌事女官道：“锅底宴后再称。羹已出碗，再耽搁便凉了。”

“离火净入有数，出菜也有数，锅底不称，三处接不上。”

“总检已经说可出。”

苏合把最后一柄长勺搁回净布：“她只认味，不替秤杆押字。”

抬锅人将铜锅重新抬上公秤。锅底只剩浅浅一层浓羹，菌菇碎末贴在锅壁，乍看与预演时没有不同。阿绫先叫人核空锅记号，再把铜砣从大到小放进盘中。

秤杆抬起，又落下。

她报连锅重，书吏扣去锅重，得锅底净余五两七钱。

“合上了？”掌事女官问。

阿绫把七根碗筹依次翻到正面。每翻一根，盛碗人便把对应的净数念一遍。八两九钱、八两八钱、八两九钱、八两七钱、八两八钱、八两九钱、八两八钱。

数字不是从她嘴里一气吐出来的。每只碗都重新落上秤盘，碗底皮重从自己的木签上扣，杆平才让下一只近案。

小满跟着数到第五只，嘴唇动得太快，把两个八两八钱撞到一起。阿绫看她一眼：“你不报数。”

“我只在心里帮忙。”

“心里也慢一点。”

“它不听我的。”

何内侍在门外道：“那便别让它碰秤。”

几个人短短笑过，手却一只也没离开自己的汤碗。

七碗复称完，七碗合计三斤十三两八钱。总检样盏净数二两，仍在西案，既不混入七碗，也不混入锅底。阿绫没有立刻说合或不合。她把代表七碗的七枚木片一枚枚移到秤案左边，又把样盏的小牌与写着锅底五两七钱的铜牌依次放在最后。

左边是已经从锅里出来的羹，右边仍压着离火时那张四斤五两四钱的公数签。

书吏先将三斤十三两八钱写到空处，接着添上样盏二两，最后接锅底五两七钱。算珠从个位推起，满十钱进一两，满十六两进一斤。最后一枚珠子落定，他的手停了。

“念。”阿绫说。

书吏喉头动了一下：“七碗、总检样盏与锅底，合四斤五两五钱。”

掌事女官立刻道：“写错了。”

“再称。”

阿绫没有同她争。七只碗全部退回原位，薄瓷盖当面揭开。第一遍换器房秤，掌秤的人换了，报数的人也换了。每只碗先核席号，再扣自己的皮重；锅底连锅最后上秤，锅沿沾着的两滴羹也没有擦掉。

第二遍仍是四斤五两五钱。

正殿第三次催菜。来催的内侍看见七碗热羹齐齐摆着，急道：“席上都在等，差一钱能有多少？一滴水也不止。”

阿绫把一枚一钱小砣放进他掌心：“拿着。”

小砣压下去，他的手几乎没有感觉。

“就这么一点。”内侍说。

“是。”

“那还等什么？”

阿绫把小砣从他手中取回，轻轻放到秤盘。杆尖立刻沉下一格。

“秤看得见。”她说。

围在称位四周的人都盯着那根落下的杆。方才还像一句可被催过去的“一点”，如今有了铜砣的形，有了杆尖的一格。没人再说它不存在。

小满站得离秤案太近，连呼吸都放轻了。她看见第七只碗盖边沾着一点白汽，想抬手替人擦，又在半空停住：“这算不算又多一钱？”

“不碰。”阿绫说。

“我没碰。”

“所以还只是水汽。”

何内侍抱着空柴筐，认真把它往背后藏了藏：“我也不碰。今日谁碰一下，怕都要把自己称上去。”

没有人笑得出来，只听见他这句，几只本要伸向木托的手都收了回去。那一钱小砣仍在盘里，压得秤杆一动不动。

顾延章走到秤案前：“羹在热时挂壁，凉后落下，前后可有浮差。”

“所以第三遍不换锅，不擦壁，趁同样热度复。”阿绫答。

“碗盖上的水汽呢？”

“盖子不计入碗重。揭盖时滴回本碗，方才七只都是如此。”

“样盏取走的一匙可扣了？”

“离火净数之后取，二两已单列。它不算在七碗里，也不算在锅底里，三项相加才是实际总数。”

她把总检样盏也放回西案。样盏没有被送走，盏内余样与顾延章尝去的一口各有净数。书吏把这一项重新加入，方才报出的总数并未漏它。

掌事女官伸手要收第一碗：“先出六碗，留一碗查。”

苏合挡在木托前：“七碗同出一锅，哪一碗都不能先离称位。”

“六名旧人是宴客，耽搁不起。”

罗六娘的声音从南廊那头传来：“我们在北地等过十三年，一碗羹等得起。”

秦岳用木杖敲了一下地：“别替我们急。”

正殿席间安静下来。顾延章原本借客人等候压来的那一刻，反被六个人亲口退了回去。

第三遍开始。

这一次，七名盛碗人各自托住空盘边，不让任何人中途换碗。阿绫把铜砣逐枚擦净，器房女官复核秤星。七碗、样盏、锅底按真实离锅顺序重新走过，书吏每得一项便当众念一项，旧数不涂，新数写在旁边。

最后仍没有改动。

出菜、取样与锅底合计，比离火净入多一钱。

不是少盛了一碗，也不是锅底忘了刮。恰恰相反，这口锅在离火称净以后、七只碗盛出以前，多了秤能看见的一钱。

书吏把三次复称的旧数并排留着，没有将前两遍划黑。七名盛碗人各自仍扶着原来的木托，手心被热气熏得发红；送菜人也退在红线外，没人借着“羹会凉”把任何一碗端走。苏合看过七只碗盖、样盏和锅底，才让阿绫把每一项的时辰补到同一页上。

那页纸上没有谁的名字被提前写成罪人，只有离火、总检、盛碗、复称。可每一步都在众人眼前，谁也不能把这一钱塞回一句“差不多”里。

阿绫把“正好”的空栏划去，写下“不合，暂不出菜”。

掌事女官沉声道：“顾尚宫已总检，掌灶人还要疑谁？”

苏合看着那一钱小砣：“不疑人。先认锅。”

她把小砣留在秤盘上。杆尖压着那一格，七只汤碗一只也没有离开。

锅底多出来的，恰好是一钱。
