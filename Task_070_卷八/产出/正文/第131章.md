# 第131章 这场归册宴，由苏合掌灶

宴单送到末灶时，锅里正煮着小满的午食。

苏合揭开锅盖，看白气先直后散，用勺柄在锅沿轻磕一下。小满夹起一根菜梗尝过，说咸淡正好，她才把火退到灶口外。

“顾尚宫点你掌灶，是不是想看你到底会不会做饭？”小满问。

阿绫正在案边记柴数，头也没抬：“全宫都知道她会。若只为看做饭，站门口闻烟便成，何必摆宴。”

“你又闻不出好不好。”

“所以我没说闻味。”阿绫在木筹上刻下最后一道，“我说闻烟。”

小满端着碗闭了嘴。她如今懂了，在阿绫跟前争一句，往往会多赔两句。

苏合把宴单平铺在案上。六名北地旧人之外，还有裴宴、宗正寺两名核册官与尚宫局女官。菜有七道，冷盘、蒸物、两道热菜、一羹、一饭，末尾是一碗归册面。

没有疙瘩汤，也没有写任何临时添料。

韦典膳进门时，苏合已把每道菜旁添了三栏：领料、离火、出菜。她看完没说好坏，只问：“接不接？”

“接。”

“顾延章指名叫你。你不问为何？”

“她若肯写，早写在宴单上了。”苏合把笔搁下，“我先问这顿饭怎样做得明白。”

午后，尚宫局议宴。顾延章坐在上首，六司掌事分列两旁。她换了一身深青常服，袖缘仍收着极细的鸦青线，不看时几乎察觉不到。

“苏合，”她道，“宴单可看过了？”

“看过。”

“五日后掌灶，可有难处？”

苏合将添过栏目的副单呈上：“有三件。”

一名掌事女官当即皱眉：“尚宫点你掌宴，是抬举，不是让你改宴制。”

“不改菜，只改记法。”

“宫宴自有灶册。”

“原来的灶册只记领料和出菜。我要每道菜都能称、能记、能复核。”

殿里响起几声翻纸声。顾延章没有拦她：“说下去。”

“能称，是整料入灶、离火净数、逐盘逐碗出菜都上同一架公秤。能记，是领料人、掌勺人、称量人、送菜人各押自己的那一笔。能复核，是锅底、余料、退菜当场留在灶内，宴散以前不倒、不洗、不添。”

顾延章翻过副单：“还有一件呢？”

“赴宴的人仍可不赴。”

一名女官立即道：“归册宴既为六名旧人所设，他们临席不来，岂不是轻慢上意？”

苏合将六枚本人记号依次放到副单旁：“他们入京时写的是去留自定，不是领宴听命。哪一位临时不愿进宫，只在席号旁记‘本人不赴’，不得因此收短凭、删现名，也不得换旁人顶他的碗。”

顾延章道：“你掌的是灶，倒替客人定起了席制。”

“若人不到，灶上便少出一份。我要知道少的是哪一碗。”

“只为记数？”

“只写能写进灶册的事。”

殿侧的宗正寺书吏看过六份副记，确认“去留自定”确是原文，便在宴单席号旁添了一行小注。尚宫局女官虽不情愿，也只能押下“缺席不改名册”。

女官冷笑：“七道菜，照你这样做，客人吃到的怕不是归册面，是隔夜面。”

门边有人低下头。小满没进殿，若在这里，大约会认真问隔夜面该由谁复味。

苏合把一只空汤碗放到案前的小秤上。秤杆一沉，她移砣，待横木稳住，才道：“碗重先记，盛汤后再记。快慢在手，不在有没有册。”

她将半盏清水倒入碗中，再称一次，两次数字分别由阿绫报出。阿绫不碰水，也不尝，只盯秤杆停处。掌事女官拿起旁边另一只同样花色的空碗换上去，秤杆立刻翘高半分。

“这算什么？”女官问。

阿绫道：“算您换的碗轻三钱。若盛成一样满，汤数却不一样。”

殿外候命的宫人齐齐看向那只碗。掌事女官原想证明称量拖沓，反倒当众换出了一只不同重的器具，脸色顿时发白。

苏合只把两只碗并排放好：“所以碗也要先记。”

顾延章终于伸手，拿过那张副单。她逐栏看得很慢，看到“锅底留存”时，指尖停了一下。

“你在北地失了味觉，便处处信秤？”

“我只辨得烫、温、凉。”苏合当着满殿女官说得清楚，“咸淡、辛苦、鲜陈，仍由复味人分尝。秤不替舌头，舌头也不替秤。”

“阿绫呢？”

“她尝不出。”

“两个尝不出的人，倒要管一场宴。”

“我管火与做法，她管数。我们不写自己不知道的。”

顾延章看了她片刻，把副单交给掌事女官：“照添。公秤两架，砝码开灶前由三方合验；空器先称，锅底留到宴散。”

方才出言阻拦的人都没再说话。韦典膳在末尾押上尚食局的名，裴宴随后只押“守证”，没有替苏合担保味道。

三件要求，当场落进宴制。

顾延章又命人取来尚宫局旧灶册。册中也有称量，只记“足”“缺”，也有试味，只记“可”“不可”，落笔者多是当值掌事一人。苏合没有说旧册无用，她把自己的副单覆在旁边，指出空锅、成菜、锅底三处应当分别落数。

“一锅羹盛出去，若只写足，足是多少？”她问。

掌事女官道：“照席数分足。”

苏合拿三只大小略异的汤碗排在秤旁：“同样一勺，碗口看着都到七分，轻重却不会自己一样。写下多少，才知道有没有足。”

顾延章让人逐碗注水。三只碗的水线看似齐平，上秤后果然各差数钱。围观女官低声议论起来，旧册上那个“足”字一时显得格外单薄。

“便照你的数记。”顾延章道，“但掌宴出了差错，也照你的名问。”

“我的那一笔，我认。”苏合答。

苏合接回副单，却发现末尾多了一枚小印。印旁是顾延章亲笔添的四字：尚宫总检。

“宫宴既由尚宫局主办，”顾延章道，“总检不能省。”

掌事女官随即送上一张旧例。按例，开席前尚宫可验火、验器、验成菜；每道菜送出前，也可亲自取样总检。

苏合看着“取样”二字，没有划掉。

这场所有菜都可称、可记、可复核的归册宴上，顾延章给自己留了一道能伸进菜里的手。
