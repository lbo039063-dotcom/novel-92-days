# 第一百三十二章 你要用我的册子，我要四十七个人都在

归册宴的第一张见证名单，只有三个人。

一个守料房，一个守公秤，一个守送菜门。尚宫局把名单送到末灶时，连纸都只裁了半幅，像多写一个名字便要多费一笔墨。

苏合看完，问送单女官：“其余四十四人呢？”

“不在宴差内。”

“他们手里各有一段灶册短凭。”

“正因如此，更不必都进来。呈上短凭，由三人合并核录即可。”

阿绫把纸接过去，沿着三个人名往下量了一掌：“空处够写。”

女官冷冷道：“纸够，宫门不够。”

当日下午，苏合带着名单去见顾延章。她没带那本总灶册，只带了一只空匣。

顾延章看见匣子，问：“你的册子呢？”

“分在四十七个人手里。”

“宫宴将近，不归总册，如何调度？”

“他们各认一笔，进灶后再按菜序拼起来。”

顾延章抬眼：“四十七人全进宫宴？苏合，归册宴不是市集开锅。”

“市集开锅也没这么多人。”罗六娘的声音从殿外传来。她没有入内，只站在阶下，把自己的蔓菁记号举过肩头，“可市集若有四十七个人盯秤，卖菜的连烂叶都不敢往下塞。”

守门女官喝她退下。罗六娘果真退了一步，纸却举得更高。

苏合道：“这四十七人不是来吃宴，也不是来听旧案。他们只认领料、下锅、离火、出菜中的一段。谁没看见，就不押谁的字。”

“三人足以通看。”顾延章说。

“三人若同站一处，另一处便没人。若一本总册被拿走，三个人的名字也一起没了。”

“你不信尚宫局保得住一本册子？”

“我信纸能被拿走。”

顾延章让掌事女官把原定三人的名字念出来，又问阶下：“你们可愿由这三人代认？”

守料房的人先摇头：“我没进过灶，不认锅。”

守公秤的接着道：“我能认秤星，没送过菜，不认殿门。”

守送菜门的更干脆：“我连哪筐菌菇从料房出来都没看见。”

三个被选作代表的人没有借机揽下整册，反而各自把不能认的事说了。掌事女官低声斥他们不知抬举，守秤的人却道：“多认一笔，出事时不是多一份抬举，是多一桩说不清。”

阶下有人应了一声。不是喝彩，只是一口憋了许久的气终于吐出来。

殿中一下静了。

一名掌事女官上前道：“放肆。”

裴宴站在苏合身后，始终没有替她开口。直到那女官命人收走空匣，他才把宗正寺文牒放到案上：“宴请六名母族旧人，我只问一句。见证人若少四十四个，他们可否不赴宴？”

顾延章看向他：“殿下以赴宴相挟？”

“去留自定。”裴宴道，“写在每个人手里的副本上。”

阶下忽然响起纸页翻动声。

不止罗六娘。四十七名曾在末灶、尚食局、冷宫外院与运送路上各自留过短凭的人，分站在长阶两侧。他们没有同捧一册，每个人手里只有一张窄纸。有人记一筐菜进了哪扇门，有人记一口锅何时离火，有人只记自己端过哪一盘。

守门女官方才只当他们是候差宫人，直到纸一起举起，才看见每张边角都有不同记号。

顾延章问：“谁许他们聚到这里？”

苏合道：“没人聚。他们依名单次序，一个个来递自己的请入凭。”

第一名宫女走上阶，只道：“我认料房青菜出门那一笔。别的，我不认。”

第二名内侍接着上前：“我认第二架秤的秤砣。锅里是什么，我不认。”

第三个人声音发抖，纸却举得稳：“我只认送菜门开过几次。”

每说完一人，便把短凭放进空匣，再退回阶下。掌事女官想命人拦，裴宴却让书吏就在阶边记“本人请入，只认一笔”。

十张、二十张、三十张。

人数不是写在一张名单上的空数，是一双双走上台阶的脚。有人旧鞋沾灰，有人新靴硌脚，走到第三十六个时，一个小内侍紧张得同手同脚，后头的人低声提醒：“你只认秤，不必把自己也称了。”

阶下憋出一阵极轻的笑。小内侍红着脸，把短凭按在匣中：“我认秤杆停稳，不认旁的。”

第四十七张落下，空匣正好装满。

其中也有人走到台阶前又退回去。一个年轻宫女说自己只看过旧册签押，从未进过正式宫宴，怕记错时辰。苏合没有劝她壮胆，只让她把“只认旧凭笔迹”写在纸上，正式宴时留在外院核笔，不进灶门。

另一人愿意认菜筐，却不愿在顾尚宫面前开口。裴宴让书吏当场念她的短凭，她只需核过记号、点头或摇头。顾延章没有反对，因她若反对，便等于要求一个没看见别处的人替整本册说话。

四十七人不是四十七张同样的胆子。有的敢抬头，有的只肯看纸，有的声音小到要贴近才听见。可每个人都保住了“不知道便不认”的那一块空白。

苏合将匣子推到顾延章案前：“您要用我的册子，我要四十七个人都在。”

顾延章没有立即答应。她翻过几张短凭，指尖在各人名字旁停了停。每张能证明的都极窄。抽掉一张，不至于毁掉整场；可拿走一匣，也拿不走阶下四十七个人各自记得的那一刻。

“灶院容不下。”她道。

“分批。”苏合答，“领料一批，入锅一批，称量一批，送菜一批。见完自己的那一笔便退到外院，不碰别人的纸。”

“殿门内最多留三人。”

“送菜段三人足够，其余守在各自看得见的地方。”

顾延章与六司掌事低声商议。阶下无人再举纸催逼。片刻后，她提笔划去原名单末尾的封线，添了“分段轮入”四字。

四十七人全部获准入场，不同处，不同时，却都能亲眼认回自己的那一笔。

掌事女官收走名单前，又呈上尚宫总检的细则。顾延章当众删去验尝、改单两项，只留一项不许苏合再议。

每道菜离火称毕，尚宫仍有亲持一匙、入菜总检之权。
