# 第三卷审查记录

## 一次性审查结论

初审硬字数、段落、同日浮字与终章空白碗边界通过；发现以下阻断点：

1. 苏蕙伤指被误写为临死前，与第1—26章“离宫前三日受伤”冲突。
2. 第29章失言陷阱中，苏合先说出了右手食指，推理无效。
3. 终局过度依赖本卷新增的旧食盒原内盖与油印。
4. 第90日才出现的亲自开门条款来源不清。
5. 第35—36章第二份辛十三在糖与糖勺之间前后矛盾。
6. 第36章行动压力不构成新信息钩子。
7. 第38章小满的反应像是能看见浮字。
8. 裴宴十三年前最初被幽禁的起因未收束。

## 已执行修订

- 伤指统一为苏蕙离宫前三日受刑；死亡投毒在第37章由沈氏失言另行坐实。
- 第29章改为苏合只问“拿走的东西”，由沈氏主动说出右手食指。
- 删除原内盖、油印及其定罪作用；终局改用既有验膳单、辛十三原签、真领料签、周内官供词与护指毒料。
- 亲自开门条款前置为沈氏停职前已写入第92日当值牌；请释副签收束“开门即移宫”。
- 第35章改为只知毒料会随糖入锅、藏处不明；第36章揭晓藏在中空糖勺。
- 第36章新信息钩子改为毒勺夹层的沈氏值房旧记号。
- 第38章改为小满只看见苏合怔住，不能看见具体浮字。
- 第28章以既有请释副签补明：沈氏用假膳账反咬年幼裴宴夜闯膳房，导致十三年前幽禁。

依照写作流程，本批次审查只运行一次；以上修订完成后不重复调用审查 Agent，改由本地硬指标与关键词检查验收。
